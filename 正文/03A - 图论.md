## 第三章：图论

### 常见概念

> oriented graph：有向图
> 
> bidirectional edges：双向边

平面图：若能将无向图 $G=(V,E)$ 画在平面上使得任意两条无重合顶点的边不相交，则称 $G$ 是平面图。

无向正权图上某一点的偏心距：记为 $ecc(u) = \max \big\{ dist(u, v) \big\}$ ，即以这个点为源，到其他点的**所有最短路的最大值**。如下图 $A$ 点，$ecc(A)$ 即为 $12$ 。

图的直径：定义为 $d = \max \big\{ ecc(u) \big\}$ ，即**最大的偏心距**，亦可以简化为图中最远的一对点的距离。

图的中心：定义为 $arg=\min \big\{ ecc(u)\big\}$ ，即**偏心距最小的点**。如下图，图的中心即为 $B$ 点。

图的绝对中心：可以定义在边上的图的中心。

图的半径：图的半径不同于圆的半径，其不等于直径的一半（但对于绝对中心定义上的直径而言是一半）。定义为 $r = \min \big\{ ecc(u) \big\}$ ，即**中心的偏心距**。计算方式：使用全源最短路，计算出所有点的偏心距，再加以计算。

### 单源最短路径（SSSP问题）

#### Dijkstra 算法与最短路径树

边权非负时，用优先队列求源点到各点的最短距离。点从 1 编号，不可达为 `INF`，需要的距离须小于 `INF`。时间 $O(N+M\log(M+1))$，空间 $O(N+M)$。

`Dijkstra` 的 `add(x,y,w)` 加一条有向边，无向边要正反各加一次。`work(s)` 后用 `getDis(x)` 查距离。有时还要输出路径经过了哪些边，此时用 `ShortestPathTree`，它的 `add(x,y,w,id)` 一次加一条无向边。只在距离**严格变短**时换父边，避免零权边把父子关系改成环。

```c++
struct Dijkstra {
    static constexpr int INF = 1e18;
    int n;
    bool record;
    vector<vector<array<int, 3>>> ver;
    vector<int> dis, pre, preId, preWeight;
    Dijkstra(int n, bool record = false)
        : n(n), record(record), ver(n + 1), dis(n + 1),
          pre(record ? n + 1 : 0), preId(pre.size()), preWeight(pre.size()) {}
    void add(int x, int y, int w, int id = 0) {
        ver[x].push_back({y, w, id});
    }
    void init() {
        fill(dis.begin(), dis.end(), INF);
        fill(pre.begin(), pre.end(), 0);
        fill(preId.begin(), preId.end(), 0);
        fill(preWeight.begin(), preWeight.end(), 0);
    }
    void work(int s = 1) {
        init();
        using PII = pair<int, int>;
        priority_queue<PII, vector<PII>, greater<PII>> q;
        q.emplace(dis[s] = 0, s);
        while (!q.empty()) {
            auto cur = q.top();
            q.pop();
            int d = cur.first, x = cur.second;
            if (d != dis[x]) continue;
            for (auto e : ver[x]) {
                int y = e[0], w = e[1];
                if (w >= dis[y] - d) continue;
                dis[y] = d + w;
                if (record) {
                    pre[y] = x;
                    preId[y] = e[2];
                    preWeight[y] = w;
                }
                q.emplace(dis[y], y);
            }
        }
    }
    int getDis(int x) { return dis[x]; }
};
constexpr int Dijkstra::INF;

struct ShortestPathTree : Dijkstra {
    ShortestPathTree(int n) : Dijkstra(n, true) {}
    void add(int x, int y, int w, int id) {
        Dijkstra::add(x, y, w, id);
        Dijkstra::add(y, x, w, id);
    }
    vector<int> getEdgeIds() {
        vector<int> ids;
        for (int x = 1; x <= n; ++x)
            if (pre[x]) ids.push_back(preId[x]);
        return ids;
    }
    int getWeightSum() {
        return accumulate(preWeight.begin(), preWeight.end(), 0LL);
    }
};
```

`ShortestPathTree` 跑完 `work(s)` 后，`getEdgeIds()` 返回所选边的编号，`getWeightSum()` 返回这些边的权值和。树只包含源点能到达的点。从树根到每个点走的都是原图中的最短路。只求距离时，抄到 `constexpr int Dijkstra::INF;` 即可。

**0–1 BFS。** 边权只有 0 和 1 时，可把堆换成双端队列。距离变短后，走 0 权边就把终点放到队首，走 1 权边就放到队尾，时间 $O(N+M)$。

#### （负权图、判负环）Bellman–Ford 算法

> **用途：** 计算最短路并标记受到源点可达负环影响的顶点。
>
> **复杂度：** $O(NM+N)$ 时间，$O(N+M)$ 空间。
>
> **使用条件：** 允许负权。参与松弛的距离和加法结果须能存入 `int`，可达路径长度须在 `INF` 范围内。查询有限最短路前，先排除不可达和受负环影响的点。

先原地松弛至多 $N-1$ 轮。随后用仍能松弛的边标记起点可达的负环影响，并沿边传播标记。传播时距离数组保持固定。若题目限制路径最多经过几条边，需另用上一轮距离的备份进行松弛。

```c++
struct BellmanFord {
    static constexpr int INF = 1e18;
    int n;
    vector<tuple<int, int, int>> ver;
    vector<int> dis, chk;
    BellmanFord(int n) : n(n), dis(n + 1), chk(n + 1) {}
    void add(int x, int y, int w) {
        ver.push_back({x, y, w});
    }
    void init() {
        fill(dis.begin(), dis.end(), INF);
        fill(chk.begin(), chk.end(), 0);
    }
    void work(int s = 1) {
        init();
        dis[s] = 0;
        for (int i = 1; i < n; ++i) {
            bool upd = false;
            for (const auto &e : ver) {
                int x, y, w;
                tie(x, y, w) = e;
                if (dis[x] != INF && dis[x] + w < dis[y]) {
                    dis[y] = dis[x] + w;
                    upd = true;
                }
            }
            if (!upd) return;
        }
        for (int i = 1; i <= n; ++i) { // 标记并传播负环影响
            bool upd = false;
            for (const auto &e : ver) {
                int x, y, w;
                tie(x, y, w) = e;
                if (!chk[y] && (chk[x] || (dis[x] != INF && dis[x] + w < dis[y]))) {
                    chk[y] = 1;
                    upd = true;
                }
            }
            if (!upd) break;
        }
    }
    int getDis(int x) {
        return dis[x];
    }
    bool cantReach(int x) {
        return dis[x] == INF;
    }
    bool inNegLoop(int x) {
        return chk[x];
    }
};
constexpr int BellmanFord::INF;
```

用法：先 `BellmanFord G(n);` ，再 `G.add(x, y, w);` 加边。调用 `G.work(s);` 后，`G.getDis(x)` 表示源点到 `x` 的最短距离；若 `G.cantReach(x)` 为真则不可达，若 `G.inNegLoop(x)` 为真则说明该点受到负环影响。

### （多源最短路）Floyd 算法

> **用途：** 用 Floyd 求所有点对的最短路。
>
> **复杂度：** $O(N^3)$ 时间，$O(N^2)$ 空间。
>
> **使用条件：** 有向边逐条添加，有限距离须小于 INF/2，无负环。

使用邻接矩阵存图，可以处理负权边，以 $\mathcal{O}(N^3)$ 的复杂度计算。**注意，这里建立的是单向边，计算双向边需要额外加边**。

```c++
struct Floyd {
    static constexpr int INF = 1e18;
    int n;
    vector<vector<int>> dis;
    Floyd(int n) {
        this->n = n;
        dis.resize(n + 1, vector<int>(n + 1, INF));
        for (int i = 1; i <= n; ++i) {
            dis[i][i] = 0;
        }
    }
    void init() {
        for (int i = 1; i <= n; ++i) {
            fill(dis[i].begin(), dis[i].end(), INF);
            dis[i][i] = 0;
        }
    }
    void add(int x, int y, int w) { // 如果是无向图，再补一条 add(y, x, w)
        dis[x][y] = min(dis[x][y], w);
    }
    void work() {
        for (int k = 1; k <= n; ++k) {
            for (int i = 1; i <= n; ++i) {
                for (int j = 1; j <= n; ++j) {
                    if (dis[i][k] >= INF / 2 || dis[k][j] >= INF / 2) continue;
                    dis[i][j] = min(dis[i][j], dis[i][k] + dis[k][j]);
                }
            }
        }
    }
    int getDis(int x, int y) {
        return dis[x][y];
    }
    bool cantReach(int x, int y) {
        return dis[x][y] >= INF / 2;
    }
};
constexpr int Floyd::INF;
```

用法：先 `Floyd G(n);` ，再 `G.add(x, y, w);` 加边；若是无向图就双向加边。调用 `G.work();` 后，`G.getDis(x, y)` 表示 `x` 到 `y` 的最短距离；若 `G.cantReach(x, y)` 为真则表示不可达。

### 最小生成树（MST问题）

#### （稠密图）Prim算法

> **用途：** 计算无向图的最小生成树权值。
>
> **复杂度：** $O(N^2+M)$ 时间，$O(N^2)$ 空间。
>
> **使用条件：** 允许负边、重边；不连通返回 INF。

使用邻接矩阵存图，以 $\mathcal{O}(N^2+M)$ 的复杂度计算，思想与 $\tt djikstra$ 基本一致。

```c++
struct Prim {
    static constexpr int INF = 1e18;
    int n;
    vector<vector<int>> g;
    vector<int> dis, vis;
    Prim(int n) {
        this->n = n;
        g.resize(n + 1, vector<int>(n + 1, INF));
        dis.resize(n + 1);
        vis.resize(n + 1);
        for (int i = 1; i <= n; ++i) {
            g[i][i] = 0;
        }
    }
    void init() {
        fill(dis.begin(), dis.end(), INF);
        fill(vis.begin(), vis.end(), 0);
    }
    void add(int x, int y, int w) {
        g[x][y] = g[y][x] = min(g[x][y], w);
    }
    int work() {
        init();
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            int t = -1;
            for (int j = 1; j <= n; ++j) {
                if (!vis[j] && (t == -1 || dis[j] < dis[t])) {
                    t = j;
                }
            }
            vis[t] = 1;
            if (i && dis[t] >= INF / 2) return INF;
            if (i) ans += dis[t];
            for (int j = 1; j <= n; ++j) {
                dis[j] = min(dis[j], g[t][j]);
            }
        }
        return ans;
    }
};
constexpr int Prim::INF;
```

用法：先 `Prim G(n);` ，再 `G.add(x, y, w);` 加无向边。调用 `G.work();` 返回最小生成树边权和；若返回值大于等于 `Prim::INF / 2` 则说明原图不连通，无法生成最小生成树。

#### （稀疏图）Kruskal算法

> **用途：** 计算无向图的最小生成树权值。
>
> **复杂度：** $O(M\log(M+1)+N)$ 时间，$O(N+M)$ 空间。
>
> **使用条件：** 允许负边、重边；不连通返回 INF。

平均时间复杂度为 $\mathcal{O}(M\log M)$ ，简化了并查集。

```c++
struct Kruskal {
    struct DSU {
        vector<int> fa;
        DSU(int n) : fa(n + 1) {
            iota(fa.begin(), fa.end(), 0);
        }
        int get(int x) {
            while (x != fa[x]) {
                x = fa[x] = fa[fa[x]];
            }
            return x;
        }
        bool merge(int x, int y) { // 设x是y的祖先
            x = get(x), y = get(y);
            if (x == y) return false;
            fa[y] = x;
            return true;
        }
        bool same(int x, int y) {
            return get(x) == get(y);
        }
    };

    static constexpr int INF = 1e18;
    using TII = tuple<int, int, int>;
    int n;
    vector<TII> ver;
    vector<char> used; // 排序后的边是否被选入最小生成树
    Kruskal(int n) {
        this->n = n;
    }
    void add(int x, int y, int w) {
        ver.push_back({w, x, y}); // 注意顺序
    }
    int work() {
        DSU dsu(n);
        __int128 ans = 0;
        int cnt = 0;
        sort(ver.begin(), ver.end());
        used.assign(ver.size(), 0);
        for (int i = 0; i < (int)ver.size(); ++i) {
            auto item = ver[i];
            auto w = get<0>(item);
            auto x = get<1>(item);
            auto y = get<2>(item);
            if (!dsu.merge(x, y)) continue;
            used[i] = 1;
            ans += w;
            cnt++;
        }
        if (cnt != n - 1 || ans >= INF) return INF;
        return ans;
    }
};
constexpr int Kruskal::INF;
```

用法：先 `Kruskal G(n);` ，再 `G.add(x, y, w);` 加无向边。调用 `G.work();` 返回最小生成树边权和；若返回值等于 `Kruskal::INF` 表示没有得到生成树，输入应保证生成树权值在 `(-INF, INF)` 内。

#### 严格次小生成树

先求一棵最小生成树。每加一条未选的边 $(u,v,w)$，树上 $u$ 到 $v$ 的路径就与它围成一个环。为了让总权值**严格增加**，删掉路径上小于 $w$ 的最大边。若路径最大边恰好等于 $w$，就看第二大的不同边权。枚举所有未选边，取最小的正增量。

把下面的函数接到 `Kruskal` 后。`strictSecondMst(G)` 返回严格次小生成树的总权值，原图不连通或没有严格次小解时返回 `Kruskal::INF`。允许重边、负权，忽略自环。有限答案应在 `(-INF, INF)` 内，边权需大于 `int` 的最小值。除 Kruskal 外，倍增和查询共用 $O((N+M)\log N)$ 时间、$O(N\log N)$ 空间。

```c++
int strictSecondMst(Kruskal &g) {
    int mst = g.work(), n = g.n;
    if (mst == Kruskal::INF) return mst;
    const int none = numeric_limits<int>::lowest();
    using Top = pair<int, int>;
    auto merge = [&](Top a, Top b) {
        for (int w : {b.first, b.second}) {
            if (w > a.first) a = {w, a.first};
            else if (a.first > w && w > a.second) a.second = w;
        }
        return a;
    };

    vector<vector<pair<int, int>>> tree(n + 1);
    for (int i = 0; i < (int)g.ver.size(); ++i) {
        if (!g.used[i]) continue;
        auto e = g.ver[i];
        int w = get<0>(e), u = get<1>(e), v = get<2>(e);
        tree[u].emplace_back(v, w);
        tree[v].emplace_back(u, w);
    }

    int lg = 1;
    while ((1LL << lg) <= n) ++lg;
    vector<vector<int>> up(lg, vector<int>(n + 1));
    vector<vector<Top>> top(lg, vector<Top>(n + 1, {none, none}));
    vector<int> depth(n + 1), order{1};
    for (int i = 0; i < (int)order.size(); ++i) {
        int u = order[i];
        for (auto e : tree[u]) {
            int v = e.first;
            if (v == up[0][u]) continue;
            depth[v] = depth[u] + 1;
            up[0][v] = u;
            top[0][v].first = e.second;
            order.push_back(v);
        }
    }
    for (int k = 1; k < lg; ++k)
        for (int u = 1; u <= n; ++u) {
            int p = up[k - 1][u];
            up[k][u] = up[k - 1][p];
            top[k][u] = merge(top[k - 1][u], top[k - 1][p]);
        }

    auto path = [&](int u, int v) {
        Top best{none, none};
        if (depth[u] < depth[v]) swap(u, v);
        int diff = depth[u] - depth[v];
        for (int k = lg - 1; k >= 0; --k)
            if ((diff >> k) & 1) {
                best = merge(best, top[k][u]);
                u = up[k][u];
            }
        if (u == v) return best;
        for (int k = lg - 1; k >= 0; --k)
            if (up[k][u] != up[k][v]) {
                best = merge(merge(best, top[k][u]), top[k][v]);
                u = up[k][u], v = up[k][v];
            }
        return merge(merge(best, top[0][u]), top[0][v]);
    };

    int ans = Kruskal::INF;
    for (int i = 0; i < (int)g.ver.size(); ++i) {
        if (g.used[i]) continue;
        auto e = g.ver[i];
        int w = get<0>(e), u = get<1>(e), v = get<2>(e);
        if (u == v) continue;
        Top best = path(u, v);
        int cut = w > best.first ? best.first : best.second;
        if (cut == none) continue;
        __int128 cost = (__int128)mst + w - cut;
        if (cost < ans) ans = static_cast<int>(cost);
    }
    return ans;
}
```

### 拓扑排序（Kahn 算法）

> **用途：** 求有向图的拓扑序，并判断是否有环。
>
> **复杂度：** $O(N+M)$ 时间，额外空间 $O(N)$。
>
> **使用条件：** 点编号为 $1\ldots N$，邻接表大小为 $N+1$。支持非连通图和重边。

先将所有入度为 0 的点加入序列。用序列本身作队列，按下标依次处理其中的点。每处理一个点，就删去它的出边，遇到入度降为 0 的点就加入序列。

```c++
vector<int> topsort(const vector<vector<int>> &adj) {
    int n = (int)adj.size() - 1;
    vector<int> in(n + 1), order;
    for (int x = 1; x <= n; x++) {
        for (int y : adj[x]) ++in[y];
    }
    for (int x = 1; x <= n; x++) {
        if (in[x] == 0) order.push_back(x);
    }
    for (int i = 0; i < (int)order.size(); i++) {
        for (int y : adj[order[i]]) {
            if (--in[y] == 0) order.push_back(y);
        }
    }
    return order;
}
```

用 `adj[x].push_back(y);` 加有向边。调用 `auto order = topsort(adj);`，若 `(int)order.size() == n`，则得到一组完整的拓扑序；否则图中有环，返回算法结束前依次移出的所有点。

### 最长路（topsort+DP算法）

> **用途：** 求 DAG 中源点到各点的最长路。
>
> **复杂度：** $O(N+M)$ 时间和空间。
>
> **使用条件：** 输入须为 DAG，可含负权。

按上一节的拓扑排序依次处理各点。取出一个源点可达的点时，用它的当前距离更新出邻点的最长距离。

```c++
struct DAG {
    static constexpr int INF = 1e18;
    int n;
    vector<vector<pair<int, int>>> ver;
    vector<int> deg, dis;
    DAG(int n) : n(n) {
        ver.resize(n + 1);
        deg.resize(n + 1);
        dis.resize(n + 1);
    }
    void add(int x, int y, int w) {
        ver[x].push_back({y, w});
        ++deg[y];
    }
    void init() {
        fill(dis.begin(), dis.end(), -INF);
    }
    int work(int s, int t) {
        init();
        vector<int> in = deg;
        queue<int> q;
        for (int i = 1; i <= n; i++) {
            if (in[i] == 0) {
                q.push(i);
            }
        }
        dis[s] = 0;
        while (!q.empty()) {
            int x = q.front();
            q.pop();
            for (const auto &e : ver[x]) {
                int y = e.first, w = e.second;
                if (dis[x] > -INF / 2) {
                    dis[y] = max(dis[y], dis[x] + w);
                }
                --in[y];
                if (in[y] == 0) {
                    q.push(y);
                }
            }
        }
        return dis[t];
    }
    int getDis(int x) {
        return dis[x];
    }
};
constexpr int DAG::INF;
```

用法：先 `DAG G(n);` ，再 `G.add(x, y, w);` 建有向边。调用 `G.work(s, t);` 返回从 `s` 到 `t` 的最长路；若需要查询任意点的最长路值，可在运行后调用 `G.getDis(x)` 。

### 缩点（Tarjan 算法）

#### （有向图）强连通分量缩点

> **用途：** 求原点的强连通分量编号并建立缩点图。
>
> **复杂度：** $O(N+M)$ 时间和空间。
>
> **使用条件：** 缩点图可有重复边。先加完边，再调用 work。

将每个强连通分量（SCC）缩成一个点，保留分量之间的有向边，得到缩点图。

> 性质：缩点后的图拥有拓扑序 $color_{cnt}, color_{cnt-1},…,1$ ，可以不需再另跑一遍 $\tt topsort$ ；缩点后的图是一张有向无环图（ $\tt DAG$ 、拓扑图）。

```c++
struct SCC {
    int n, now, cnt;
    vector<vector<int>> ver;
    vector<int> dfn, low, col, S;

    SCC(int n) : n(n), ver(n + 1), low(n + 1) {
        dfn.resize(n + 1, -1);
        col.resize(n + 1, -1);
        now = cnt = 0;
    }
    void add(int x, int y) {
        ver[x].push_back(y);
    }
    void tarjan(int x) {
        dfn[x] = low[x] = now++;
        S.push_back(x);
        for (auto y : ver[x]) {
            if (dfn[y] == -1) {
                tarjan(y);
                low[x] = min(low[x], low[y]);
            } else if (col[y] == -1) {
                low[x] = min(low[x], dfn[y]);
            }
        }
        if (dfn[x] == low[x]) {
            int pre;
            cnt++;
            do {
                pre = S.back();
                col[pre] = cnt;
                S.pop_back();
            } while (pre != x);
        }
    }
    auto work() { // [cnt 新图的顶点数量]
        for (int i = 1; i <= n; i++) { // 避免图不连通
            if (dfn[i] == -1) {
                tarjan(i);
            }
        }

        vector<int> siz(cnt + 1); // siz 每个 scc 中点的数量
        vector<vector<int>> adj(cnt + 1);
        for (int i = 1; i <= n; i++) {
            siz[col[i]]++;
            for (auto j : ver[i]) {
                int x = col[i], y = col[j];
                if (x != y) {
                    adj[x].push_back(y);
                }
            }
        }
        return make_tuple(cnt, adj, col, siz);
    }
};
```

用法：先 `SCC G(n);` ，再 `G.add(x, y);` 建有向边。调用 `auto res = G.work();` 后，`get<0>(res)` 是缩点后新图点数，`get<1>(res)` 是新图邻接表，`get<2>(res)[i]` 表示原图点 `i` 属于哪个强连通分量，`get<3>(res)[i]` 表示第 `i` 个强连通分量大小。

**批量查可达性。** 缩点后为每个分量开一个 `bitset`，先把自己标为可达。按分量编号从小到大处理，把每个直接后继的 `bitset` 或到当前分量上。分量数较多时，先估算约 $K^2$ 位的内存。

#### （无向图）割边缩点

> **用途：** 求割边与边双连通分量，并构造边双缩点图。
>
> **复杂度：** $O(N + M \log N)$ 时间，$O(N+M)$ 空间。若只求分量和缩点图，删去两个集合及其插入语句即可做到 $O(N+M)$ 时间。
>
> **使用条件：** 无向图，允许重边、自环及非连通图。加完所有边后再调用 `work()`。

**割边（桥）**是删除后使连通分量数增加的边。删去所有桥，剩下的各个连通分量就是边双连通分量（E-DCC），单点也可以自成分量。每点恰好属于一个边双，同一边双内的任意两个不同点之间有两条边不相交的路径，两条路径可以经过同一个点。

把每个边双缩成一点，原来的桥成为缩点图的边。原图连通时得到一棵树，否则得到森林。DFS 用边编号跳过父边，因此通往父节点的另一条重边仍会用于更新 `low`。

```c++
struct EDCC {
    int n, m, now, cnt;
    vector<vector<array<int, 2>>> ver;
    vector<int> dfn, low, col, S;
    set<array<int, 2>> bridge, direct; // 如果不需要，删除这一部分可以得到一些时间上的优化

    EDCC(int n) : n(n), ver(n + 1), dfn(n + 1), low(n + 1), col(n + 1) {
        m = now = cnt = 0;
    }
    void add(int x, int y) {
        ver[x].push_back({y, m});
        ver[y].push_back({x, m++});
    }
    void tarjan(int x, int fa) {
        dfn[x] = low[x] = ++now;
        S.push_back(x);
        for (const auto &e : ver[x]) {
            int y = e[0], id = e[1];
            if (!dfn[y]) {
                tarjan(y, id);
                low[x] = min(low[x], low[y]);
                if (dfn[x] < low[y]) {
                    bridge.insert({x, y});
                } else {
                    direct.insert({x, y});
                }
            } else if (id != fa && dfn[y] < dfn[x]) {
                direct.insert({x, y});
                low[x] = min(low[x], dfn[y]);
            }
        }
        if (dfn[x] == low[x]) {
            int pre;
            cnt++;
            do {
                pre = S.back();
                col[pre] = cnt;
                S.pop_back();
            } while (pre != x);
        }
    }
    auto work() {
        for (int i = 1; i <= n; i++) { // 避免图不连通
            if (!dfn[i]) {
                tarjan(i, -1);
            }
        }
        vector<int> siz(cnt + 1);
        vector<vector<int>> adj(cnt + 1);
        for (int i = 1; i <= n; i++) {
            siz[col[i]]++;
            for (const auto &e : ver[i]) {
                int x = col[i], y = col[e[0]];
                if (x != y) {
                    adj[x].push_back(y);
                }
            }
        }
        return make_tuple(cnt, adj, col, siz);
    }
};
```

先用 `EDCC G(n);` 和 `G.add(x, y);` 建图。`work()` 依次返回分量数、缩点图邻接表、每个原图点的分量编号、各分量的点数。`G.bridge` 保存桥的端点对，`G.direct` 保存非桥边的定向端点对。树边从父点指向子点，返祖边从后代指向祖先。两个集合都按端点对存储，`direct` 会合并同向重边且忽略自环。

#### （无向图）割点缩点

> **用途：** 求割点与点双连通分量，并可建立圆方树。
>
> **复杂度：** $O(N+M)$ 时间和空间。
>
> **使用条件：** 无向图，允许重边及非连通图，忽略自环。加完所有边后再求解。

割点（割顶）是删除该点及所有关联边后，使连通分量数增加的点。两个不同的点原本连通，且删除任何一个其他点后仍然连通，就称这两点点双连通。点双连通分量（V-DCC）是极大的无割点连通子图。按照本模板的约定，一条桥及其两端、一个孤立点都可以单独成块。

每个非割点恰好属于一个点双，每个割点属于至少两个点双。两个不同点双至多共享一个点，共享点必是割点。每条非自环边恰好属于一个点双。

每个点双对应一个方点。广义圆方树保留所有原图点作为圆点，按所属关系连接圆点和方点。只保留割点作为圆点的版本称为块割树。两种建图在原图连通时得到一棵树，否则得到森林。

这份实现更新 `low` 时也考虑父边。对 DFS 树边 $x\to y$，这相当于把标准的 $low_y$ 与 $dfn_x$ 取较小值，所以 $low_y\ge dfn_x$ 的判断结果不变。判桥用的是严格大于，需要使用上面的边双模板。每发现一个点双，弹栈到 $y$，再把 $x$ 加入该点双并留在栈中，供其他点双使用。

```c++
struct V_DCC {
    int n;
    vector<vector<int>> ver, col;
    vector<int> dfn, low, S;
    int now, cnt;
    vector<bool> point; // 记录是否为割点

    V_DCC(int n) : n(n), ver(n + 1), col(n + 1), dfn(n + 1), low(n + 1),
                  now(0), cnt(0), point(n + 1) {}
    void add(int x, int y) {
        if (x == y) return; // 忽略自环
        ver[x].push_back(y);
        ver[y].push_back(x);
    }
    void tarjan(int x, int root) {
        low[x] = dfn[x] = ++now;
        if (ver[x].empty()) { // 孤立点单独成块
            ++cnt;
            col[cnt].push_back(x);
            return;
        }
        S.push_back(x);

        int flag = 0;
        for (auto y : ver[x]) {
            if (!dfn[y]) {
                tarjan(y, root);
                low[x] = min(low[x], low[y]);
                if (dfn[x] <= low[y]) {
                    flag++;
                    if (x != root || flag > 1) {
                        point[x] = true; // 标记为割点
                    }
                    int pre;
                    cnt++;
                    do {
                        pre = S.back();
                        col[cnt].push_back(pre);
                        S.pop_back();
                    } while (pre != y);
                    col[cnt].push_back(x);
                }
            } else {
                low[x] = min(low[x], dfn[y]);
            }
        }
    }
    pair<int, vector<vector<int>>> rebuild() { // [新图的顶点数量, 新图]
        work();
        int tot = n + cnt;
        vector<vector<int>> adj(tot + 1);
        for (int i = 1; i <= cnt; i++) {
            for (int x : col[i]) {
                adj[n + i].push_back(x);
                adj[x].push_back(n + i);
            }
        }
        return {tot, adj};
    }
    void work() {
        for (int i = 1; i <= n; ++i) { // 避免图不连通
            if (!dfn[i]) {
                tarjan(i, i);
                S.clear();
            }
        }
    }
};
```

先用 `V_DCC G(n);` 和 `G.add(x, y);` 建图。调用 `G.work();` 后，`G.point[x]` 表示原图点 `x` 是否为割点，`G.col[i]` 保存第 `i` 个点双的成员。也可直接调用 `G.rebuild();`，返回广义圆方树的点数和邻接表。圆点沿用原编号 `1...n`，第 `i` 个点双对应方点 `n + i`。

两份模板都使用递归 DFS，深链上需留意栈空间。

### 一般图最大匹配（Micali–Vazirani 算法）

> **用途：** 求一般无向图的最大匹配边数，并返回配对方案。
>
> **复杂度：** 本实现使用按大小合并和路径减半的并查集，时间上界为 $O((N+M)\sqrt N\,\alpha(N))$，空间为 $O(N+M)$。$\alpha$ 为反阿克曼函数。论文的 $O(M\sqrt N)$ 界使用了线性集合合并，并省略了孤立点的处理开销。
>
> **使用条件：** 无向无权图，点编号为 $1\ldots N$，允许重边，忽略自环。展开花使用递归。

每轮先从所有未匹配点出发，按奇偶性维护交替路的最短层数 `ev` 和 `od`。随后按 `ten` 给出的层次对候选边做双向 DFS（DDFS）。两侧若到达不同的未匹配点，就展开花并增广；若只能汇聚到同一点，就以它为花基，用并查集维护这个花。这里的 `BRIDGE` 是 MV 搜索中的候选边分类。

一轮会找出一组点不相交的最短增广路，增广后最短增广路变长，因此只有 $O(\sqrt N)$ 轮。每轮重置 $O(N+M)$ 个状态，分层、DDFS、展开和删除按点边摊还，并查集查询另计 $\alpha(N)$ 因子。

```c++
struct MV {
    using P=pair<int,int>;
    enum{INF=1000000000,NEW=0,PROP=1,BRIDGE=2};
    struct Edge{int v,rev,type;};
    struct Petal{int a,b,x,y;};
    int n,tim,openTime;
    vector<vector<Edge>> g;
    vector<int> mat,ev,od,col,dead,ptr,fa,sz,base,par,seen;
    vector<vector<int>> pre;
    vector<vector<P>> ch;
    vector<Petal> pet;
    queue<int> q;
    MV(int n):n(n),g(n+1){}
    void add(int u,int v){
        if(u==v) return;
        int a=g[u].size(),b=g[v].size();
        g[u].push_back({v,b,NEW}),g[v].push_back({u,a,NEW});
    }
    int get(int x){
        while(x!=fa[x]) {
            fa[x]=fa[fa[x]];
            x=fa[x];
        }
        return x;
    }
    int bud(int x){return base[get(x)];}
    void merge(int x,int y){
        assert(bud(x)==x&&bud(y)==y&&x!=y);
        par[x]=y;
        int a=get(x),b=get(y);
        if(sz[a]<sz[b]) swap(a,b);
        fa[b]=a,sz[a]+=sz[b],base[a]=y;
    }
    int level(int x){return min(ev[x],od[x]);}
    int ten(int u,int v){
        return (mat[u]==v?od[u]+od[v]:ev[u]+ev[v])+1;
    }
    void del(int x){if(!dead[x]) dead[x]=1,q.push(x);}
    void flip(int u,int v){
        if(dead[u]||dead[v]||mat[u]==v) return;
        mat[u]=v,mat[v]=u,del(u),del(v);
    }
    int step(vector<int>&a,vector<int>&b,int c,vector<int>&s){
        int u=a.back();
        for(int &i=ptr[u];i<(int)pre[u].size();i++){
            int x=pre[u][i],v=bud(x);
            if(dead[x]) continue;
            if(!col[v]){
                a.push_back(v),s.push_back(v);
                ch[u].push_back({x,v}),col[v]=c;
                return 0;
            }
            if(v==b.back()) ch[u].push_back({x,v});
        }
        a.pop_back();
        if(a.empty()){
            int v=b.back();
            if(b.size()==1){col[v]=0;return v;}
            b.pop_back(),a.push_back(v),col[v]=c;
        }
        return 0;
    }
    P ddfs(int u,int v,vector<int>&s){
        vector<int> a{u},b{v};
        s={u,v};
        int c=++tim,d=++tim;
        col[u]=c,col[v]=d;
        while(true){
            if(!level(a.back())&&!level(b.back()))
                return {a.back(),b.back()};
            int p=level(a.back())>=level(b.back())?
                step(a,b,c,s):step(b,a,d,s);
            if(p) return {p,p};
        }
    }
    bool open(int u,int x,int t,int stamp){
        if(seen[x]==stamp) return false;
        seen[x]=stamp; // 同一次花内搜索只访问每个点一次
        if(x==t){augment(u,x);return true;}
        for(auto p:ch[x]){
            if((p.second==t||col[p.second]==col[x])&&open(p.first,p.second,t,stamp)){
                augment(u,x),flip(x,p.first);
                return true;
            }
        }
        return false;
    }
    void augment(int u,int v,bool init=false){
        while(u!=v){
            if(!init&&level(u)==ev[u]){
                int x=pre[u][0],i=0;
                while(bud(pre[x][i])!=bud(x)) i++;
                u=pre[x][i],flip(x,u);
            }else{
                auto p=pet[u];
                if((col[p.x]^1)==col[u]||col[p.y]==col[u])
                    swap(p.a,p.b),swap(p.x,p.y);
                flip(p.a,p.b);
                bool a=open(p.a,p.x,u,++openTime);
                bool b=open(p.b,p.y,par[u],++openTime);
                assert(a&&b);
                u=par[u],init=false;
            }
        }
    }
    bool phase(){
        vector<vector<int>> lev(n+1);
        vector<vector<P>> br(2*n+3);
        vector<int> lost(n+1);
        auto setlev=[&](int u,int h){
            assert(h>=0&&h<=n);
            (h&1?od[u]:ev[u])=h,lev[h].push_back(u);
        };
        for(int u=1;u<=n;u++) if(!mat[u]) setlev(u,0);
        for(int h=0;h<n;h++){
            for(int u:lev[h]) for(auto &e:g[u]){
                int v=e.v;
                if(e.type!=NEW||((od[u]==h)!=(mat[u]==v))) continue;
                if(level(v)>=h+1){
                    e.type=g[v][e.rev].type=PROP;
                    if(level(v)>h+1) setlev(v,h+1);
                    pre[v].push_back(u);
                }else{
                    e.type=g[v][e.rev].type=BRIDGE;
                    int k=ten(u,v);
                    if(k<INF) br[k].push_back({u,v});
                }
            }
            bool found=false;
            int t=2*h+1;
            for(int i=0;i<(int)br[t].size();i++){
                int u=br[t][i].first,v=br[t][i].second;
                int a=bud(u),b=bud(v);
                if(dead[a]||dead[b]||a==b) continue;
                vector<int> s;
                P r=ddfs(a,b,s);
                Petal p={u,v,a,b};
                for(int x:s){
                    if(x==r.second) continue;
                    pet[x]=p,merge(x,r.second);
                    setlev(x,t-level(x));
                    if(ev[x]>od[x]) for(auto e:g[x]){
                        int y=e.v,k=ten(x,y);
                        if(e.type==BRIDGE&&mat[x]!=y&&k<INF)
                            br[k].push_back({x,y});
                    }
                }
                if(r.first==r.second) continue;
                augment(r.first,r.second,true),found=true;
                while(!q.empty()){
                    int x=q.front();q.pop();
                    for(auto e:g[x]){
                        int y=e.v;
                        if(e.type==PROP&&!dead[y]&&level(y)>level(x)&&
                           ++lost[y]==(int)pre[y].size()) del(y);
                    }
                }
            }
            if(found) return true;
        }
        return false;
    }
    pair<int,vector<int>> work(){
        mat.assign(n+1,0);
        do{
            for(auto &a:g) for(auto &e:a) e.type=NEW;
            ev=od=vector<int>(n+1,INF);
            col=dead=ptr=seen=vector<int>(n+1);
            openTime=0;
            pre.assign(n+1,{}),ch.assign(n+1,{}),pet.assign(n+1,{});
            par.assign(n+1,0),sz.assign(n+1,1),fa.resize(n+1);
            iota(fa.begin(),fa.end(),0),base=fa,tim=1;
        }while(phase());
        return {(n+1-(int)count(mat.begin(),mat.end(),0))/2,mat};
    }
};
```

用 `MV G(n);` 初始化，`G.add(u, v);` 加无向边。`auto res = G.work();` 后，`res.first` 是最大匹配的边数，`res.second[u]` 是点 `u` 的匹配对象，等于 `0` 表示未匹配。匹配数组的下标 `0` 是占位，输出时遍历 `1...n`。

```c++
auto res = G.work();
cout << res.first << '\n';
for (int u = 1; u <= n; u++) {
    cout << res.second[u] << (u == n ? '\n' : ' ');
}
```

### 一般图最大权匹配（带权带花树算法）

> **用途：** 求一般无向图中匹配边权值和的最大值，并恢复方案。允许点未匹配。
>
> **复杂度：** 读入 $M$ 条边并求解的总时间为 $O(N^3+M)$，空间为 $O(N^2)$。矩阵按 $N$ 动态分配。
>
> **使用条件：** 点编号为 $1\ldots N$。忽略自环和非正权边，重边保留最大权。

搜索先沿松弛量为 0 的边进行增广、缩花。搜索无法继续时调整对偶标号，使新的边可用，或展开标号降到 0 的花。

```c++
struct GeneralWeightedMatching {
    struct Edge{int u,v,w;};
    int n,m,tim,h;
    vector<vector<Edge>> e;
    vector<vector<int>> b,p; // 原点所属的直接子花、花上的环
    vector<int> lk,sl,st,f,s,ed,q,lab; // lk 为配对，lab 为对偶标号
    GeneralWeightedMatching(int n):n(n),m(n),
        e(2*n+1,vector<Edge>(2*n+1)),
        b(2*n+1,vector<int>(n+1)),p(2*n+1),
        lk(2*n+1),sl(lk),st(lk),f(lk),s(lk),ed(lk),lab(lk){
        for(int u=1;u<=n;u++){
            b[u][u]=u;
            for(int v=1;v<=n;v++) e[u][v]={u,v,0};
        }
    }
    void add(int u,int v,int w){
        if(u!=v&&w>e[u][v].w)
            e[u][v]={u,v,w},e[v][u]={v,u,w};
    }
    int d(const Edge &a){
        return lab[a.u]+lab[a.v]-2*a.w;
    }
    void upd(int u,int v){
        if(!sl[v]||d(e[u][v])<d(e[sl[v]][v])) sl[v]=u;
    }
    void ss(int v){
        sl[v]=0;
        for(int u=1;u<=n;u++)
            if(e[u][v].w>0&&st[u]!=v&&!s[st[u]]) upd(u,v);
    }
    void ins(int u){
        if(u<=n) q.push_back(u);
        else for(int v:p[u]) ins(v);
    }
    void mdf(int u,int v){
        st[u]=v;
        if(u>n) for(int x:p[u]) mdf(x,v);
    }
    int gr(int u,int v){
        int k=find(p[u].begin(),p[u].end(),v)-p[u].begin();
        if(k&1) reverse(p[u].begin()+1,p[u].end()),k=p[u].size()-k;
        return k;
    }
    void stm(int u,int v){
        lk[u]=e[u][v].v;
        if(u<=n) return;
        int x=b[u][e[u][v].u],k=gr(u,x);
        for(int i=0;i<k;i++) stm(p[u][i],p[u][i^1]);
        stm(x,v);
        rotate(p[u].begin(),p[u].begin()+k,p[u].end());
    }
    void aug(int u,int v){
        int x=st[lk[u]];
        stm(u,v);
        if(x) stm(x,st[f[x]]),aug(st[f[x]],x);
    }
    int lca(int u,int v){
        for(++tim;u||v;swap(u,v)) if(u){
            if(ed[u]==tim) return u;
            ed[u]=tim,u=st[lk[u]];
            if(u) u=st[f[u]];
        }
        return 0;
    }
    void shrink(int u,int a,int v){
        int x=n+1;
        while(x<=m&&st[x]) x++;
        if(x>m) m++;
        lab[x]=s[x]=0,lk[x]=lk[a],p[x]={a};
        for(int i=u,j;i!=a;i=st[f[j]])
            p[x].push_back(i),p[x].push_back(j=st[lk[i]]),ins(j);
        reverse(p[x].begin()+1,p[x].end());
        for(int i=v,j;i!=a;i=st[f[j]])
            p[x].push_back(i),p[x].push_back(j=st[lk[i]]),ins(j);
        mdf(x,x);
        for(int i=1;i<=m;i++) e[x][i].w=e[i][x].w=0;
        fill(b[x].begin(),b[x].end(),0);
        for(int i:p[x]){
            for(int j=1;j<=m;j++)
                if(e[i][j].w>0&&(!e[x][j].w||d(e[i][j])<d(e[x][j])))
                    e[x][j]=e[i][j],e[j][x]=e[j][i];
            for(int j=1;j<=n;j++) if(b[i][j]) b[x][j]=i;
        }
        ss(x);
    }
    void expand(int u){
        for(int x:p[u]) mdf(x,x);
        int a=b[u][e[u][f[u]].u],r=gr(u,a);
        for(int i=0;i<r;i+=2){
            int x=p[u][i],y=p[u][i+1];
            f[x]=e[y][x].u,s[x]=1,s[y]=sl[x]=0;
            ss(y),ins(y);
        }
        s[a]=1,f[a]=f[u];
        for(int i=r+1;i<(int)p[u].size();i++)
            s[p[u][i]]=-1,ss(p[u][i]);
        st[u]=0;
    }
    bool on(Edge a){
        int u=st[a.u],v=st[a.v];
        if(s[v]==-1){
            f[v]=a.u,s[v]=1;
            int x=st[lk[v]];
            sl[v]=sl[x]=s[x]=0,ins(x);
        }else if(!s[v]){
            int x=lca(u,v);
            if(!x){aug(u,v),aug(v,u);return true;}
            shrink(u,x,v);
        }
        return false;
    }
    bool bfs(){
        fill(s.begin(),s.end(),-1);
        fill(sl.begin(),sl.end(),0);
        q.clear(),h=0;
        for(int i=1;i<=m;i++)
            if(st[i]==i&&!lk[i]) f[i]=s[i]=0,ins(i);
        if(q.empty()) return false;
        while(true){
            while(h<(int)q.size()){
                int u=q[h++];
                if(s[st[u]]==1) continue;
                for(int v=1;v<=n;v++) if(e[u][v].w>0&&st[u]!=st[v]){
                    if(d(e[u][v])) upd(u,st[v]);
                    else if(on(e[u][v])) return true;
                }
            }
            int x=numeric_limits<int>::max()/4;
            for(int i=n+1;i<=m;i++)
                if(st[i]==i&&s[i]==1) x=min(x,lab[i]/2);
            for(int i=1;i<=m;i++)
                if(st[i]==i&&sl[i]&&s[i]!=1)
                    x=min(x,d(e[sl[i]][i])>>(s[i]+1));
            for(int i=1;i<=n;i++) if(s[st[i]]!=-1){
                if(!s[st[i]]&&lab[i]<=x) return false;
                lab[i]+=(2*s[st[i]]-1)*x;
            }
            for(int i=n+1;i<=m;i++)
                if(st[i]==i&&s[i]!=-1) lab[i]+=(2-4*s[i])*x;
            q.clear(),h=0;
            for(int i=1;i<=m;i++)
                if(st[i]==i&&sl[i]&&st[sl[i]]!=i&&!d(e[sl[i]][i])&&on(e[sl[i]][i]))
                    return true;
            for(int i=n+1;i<=m;i++)
                if(st[i]==i&&s[i]==1&&!lab[i]) expand(i);
        }
    }
    int work(){
        m=n,tim=0;
        fill(lk.begin(),lk.end(),0);
        fill(ed.begin(),ed.end(),0);
        fill(st.begin(),st.end(),0);
        iota(st.begin()+1,st.begin()+n+1,1);
        int w=0,ans=0;
        for(int i=1;i<=n;i++)
            for(int j=1;j<=n;j++) w=max(w,e[i][j].w);
        fill(lab.begin()+1,lab.begin()+n+1,w);
        while(bfs()){}
        for(int i=1;i<=n;i++)
            if(lk[i]>i) ans+=e[i][lk[i]].w;
        return ans;
    }
    vector<array<int,2>> answer(){
        vector<array<int,2>> a;
        for(int i=1;i<=n;i++)
            if(lk[i]>i) a.push_back({i,lk[i]});
        return a;
    }
};
```

用 `GeneralWeightedMatching G(n);` 初始化，调用 `G.add(u, v, w);` 加无向边。`G.work()` 返回最大权值和。`G.answer()` 返回所有匹配边，每条边只出现一次。若题目要求按点输出配对，直接读 `G.lk[i]`，其中 `0` 表示未匹配。

}

### 染色法判定二分图 (dfs算法)

> **用途：** 检查每个连通分量能否二染色。
>
> **复杂度：** $O(N+M)$ 时间，$O(N+M)$ 空间。
>
> **使用条件：** 按无向图建边。

判断一张图能否被二分染色。

```c++
struct BipartiteGraph {
    int n;
    vector<vector<int>> ver;
    vector<int> color;
    BipartiteGraph(int n) {
        this->n = n;
        ver.resize(n + 1);
        color.resize(n + 1);
    }
    void add(int x, int y) {
        ver[x].push_back(y);
        ver[y].push_back(x);
    }
    bool dfs(int x, int type) {
        color[x] = type;
        for (auto y : ver[x]) {
            if (color[y] == type) {
                return false;
            }
            if (color[y]) continue;
            if (!dfs(y, 3 - type)) {
                return false;
            }
        }
        return true;
    }
    bool work() {
        fill(color.begin(), color.end(), 0);
        for (int i = 1; i <= n; ++i) {
            if (color[i]) continue;
            if (!dfs(i, 1)) {
                return false;
            }
        }
        return true;
    }
};
```

用法：先 `BipartiteGraph G(n);` ，再 `G.add(x, y);` 加无向边。调用 `G.work();` 判断整张图是否为二分图；若需要具体染色方案，可直接查看 `G.color[i]` 的值（`1/2` 表示两种颜色）。

### 二分图最大匹配

> 二分图：一个图能被分为左右两部分，任何一条边的两个端点都不在同一部分中。
> 
> 匹配（独立边集）：一个边的集合，这些边没有公共顶点。
> 
> 二分图最大匹配即找到边的数量最多的那个匹配。
> 
> 一般我们规定，左半部包含 $n_1$ 个点（编号 $1 - n_1$），右半部包含 $n_2$ 个点（编号 $1-n_2$ ），保证任意一条边的两个端点都不可能在同一部分中。

#### 匈牙利算法解

> **用途：** 求二分图最大匹配条数或方案。
>
> **复杂度：** 逐次增广，当前代码每轮还要初始化右侧访问数组。
>
> **使用条件：** 左右部均从 1 编号。

 $\mathcal O (NM)$ 。

```c++
struct HungaryMatch {
    int n1, n2;
    vector<vector<int>> ver;
    vector<int> match;
    HungaryMatch(int n1, int n2) : n1(n1), n2(n2) {
        ver.resize(n1 + 1);
        match.resize(n2 + 1);
    }
    void add(int x, int y) { // 只需要建立左到右的单向边
        ver[x].push_back(y);
    }
    bool dfs(int x, vector<int> &vis) {
        for (auto y : ver[x]) {
            if (vis[y]) continue;
            vis[y] = 1;
            if (!match[y] || dfs(match[y], vis)) {
                match[y] = x;
                return true;
            }
        }
        return false;
    }
    int work() {
        fill(match.begin(), match.end(), 0);
        int ans = 0;
        for (int i = 1; i <= n1; ++i) {
            vector<int> vis(n2 + 1);
            if (dfs(i, vis)) {
                ans++;
            }
        }
        return ans;
    }
    vector<array<int, 2>> answer() {
        vector<array<int, 2>> ans;
        for (int i = 1; i <= n2; ++i) {
            if (match[i]) {
                ans.push_back({match[i], i});
            }
        }
        return ans;
    }
};
```

用法：先 `HungaryMatch G(n1, n2);` ，再 `G.add(x, y);` 加边。调用 `G.work();` 返回最大匹配数；若需要具体方案，可在运行后调用 `G.answer()` 获取匹配边。

#### Hopcroft–Karp

二分图点多、边多时用这版。BFS 从所有未配对的左点同时出发，找这一轮最短的增广路长度。DFS 只沿这些层走，找到路径就翻转配对。时间 $O((N+M)\sqrt N)$，空间 $O(N+M)$。

```c++
struct HopcroftKarp {
    int n;
    vector<vector<int>> ver;
    vector<int> l, r, dist, next;
    HopcroftKarp(int n, int m)
        : n(n), ver(n + 1), l(n + 1), r(m + 1), dist(n + 1), next(n + 1) {}
    void add(int x, int y) { ver[x].push_back(y); }
    bool bfs() {
        fill(dist.begin(), dist.end(), n + 1);
        queue<int> q;
        for (int x = 1; x <= n; ++x)
            if (!l[x]) q.push(x), dist[x] = 0;
        // 0 代表到达一个未配对的右点。
        while (!q.empty()) {
            int x = q.front();
            q.pop();
            if (dist[x] >= dist[0]) continue;
            for (int y : ver[x]) {
                int z = r[y];
                if (dist[z] != n + 1) continue;
                dist[z] = dist[x] + 1;
                if (z) q.push(z);
            }
        }
        return dist[0] <= n;
    }
    bool dfs(int x) {
        if (!x) return true;
        for (int &i = next[x]; i < (int)ver[x].size(); ++i) {
            int y = ver[x][i], z = r[y];
            if (dist[z] != dist[x] + 1 || !dfs(z)) continue;
            l[x] = y, r[y] = x;
            return true;
        }
        dist[x] = n + 1;
        return false;
    }
    int work() {
        fill(l.begin(), l.end(), 0);
        fill(r.begin(), r.end(), 0);
        int ans = 0;
        while (bfs()) {
            fill(next.begin(), next.end(), 0);
            for (int x = 1; x <= n; ++x)
                if (!l[x] && dfs(x)) ++ans;
        }
        return ans;
    }
    vector<array<int, 2>> answer() {
        vector<array<int, 2>> ans;
        for (int x = 1; x <= n; ++x)
            if (l[x]) ans.push_back({x, l[x]});
        return ans;
    }
};
```

左右两侧分别从 1 编号。`add(x,y)` 从左点连到右点。`work()` 从空匹配重算，返回边数。`answer()` 返回匹配边，`l[x]`、`r[y]` 可查配对，`0` 表示未匹配。

**DAG 最小点不交路径覆盖。** 要用尽量少的路径覆盖所有点，每个点恰好出现一次。把每个点复制成左右两份，每条原边 $u\to v$ 连 $u_L$ 到 $v_R$。一次匹配相当于接起来一对前后相邻的点，答案为 $N-$ 最大匹配数。

### 二分图最大权匹配（KM 算法）

> **用途：** 求原图中匹配边权之和的最大值，并恢复一组方案。点可以不匹配，两侧点数可以不同。
>
> **复杂度：** 设 $N=\max(n_1,n_2)$，求解时间 $O(N^3)$，空间 $O(N^2)$，逐条加入 $M$ 条边另需 $O(M)$ 时间。
>
> **使用条件：** 左右两侧各自从 $1$ 编号。`add` 接收非负边权，允许零权边，重边保留最大权。若输入含负权边，读入时跳过即可，因为允许点不匹配，去掉负权匹配边只会提高总权值。边权、总权值和中间计算须在整数范围内，搜索中的松弛量须小于代码里的 `1E18`。

经典 KM 求的是完全二分图的最大权完美匹配。这里先把两侧补到各有 $N$ 个点，缺边和虚点的关联边都按权值 $0$ 处理。原图中的任意匹配都能补成一个权值至少相同的完美匹配。反过来，从补齐图的完美匹配中删去补边，就得到一个权值相同的原图匹配。因此两者的最优权值相等。

例如，边 $(1,1)$ 权值为 $10$，$(1,2)$ 为 $3$，$(2,1)$ 为 $4$。最大权匹配只取 $(1,1)$，权值为 $10$；若要求先让匹配边数最多，则要取后两条边，权值为 $7$。

`ver` 存补齐后的边权，`hasEdge` 标记原图中的边。恢复方案时靠 `hasEdge` 区分真实零权边和补上的零权边。若题目要求原图中的每个点都匹配，需要让求解过程区分缺边和真实边，并检查是否有完美匹配。

```c++
struct MaxCostMatch {
    vector<int> ansl, ansr, pre;
    vector<int> lx, ly;
    vector<vector<int>> ver;
    vector<vector<bool>> hasEdge;
    int n;

    MaxCostMatch(int n) : n(n) {
        ver.resize(n + 1, vector<int>(n + 1));
        hasEdge.assign(n + 1, vector<bool>(n + 1));
        ansl.resize(n + 1, -1);
        ansr.resize(n + 1, -1);
        lx.resize(n + 1);
        ly.resize(n + 1, -1E18);
        pre.resize(n + 1);
    }
    void add(int x, int y, int w) {
        assert(w >= 0);
        ver[x][y] = max(ver[x][y], w);
        hasEdge[x][y] = true;
    }
    void bfs(int x) {
        vector<bool> visl(n + 1), visr(n + 1);
        vector<int> slack(n + 1, 1E18);
        queue<int> q;
        function<bool(int)> check = [&](int x) {
            visr[x] = 1;
            if (~ansr[x]) {
                q.push(ansr[x]);
                visl[ansr[x]] = 1;
                return false;
            }
            while (~x) {
                ansr[x] = pre[x];
                swap(x, ansl[pre[x]]);
            }
            return true;
        };
        q.push(x);
        visl[x] = 1;
        while (1) {
            while (!q.empty()) {
                int x = q.front();
                q.pop();
                for (int y = 1; y <= n; ++y) {
                    if (visr[y]) continue;
                    int del = lx[x] + ly[y] - ver[x][y];
                    if (del < slack[y]) {
                        pre[y] = x;
                        slack[y] = del;
                        if (!slack[y] && check(y)) return;
                    }
                }
            }
            int val = 1E18;
            for (int i = 1; i <= n; ++i) {
                if (!visr[i]) {
                    val = min(val, slack[i]);
                }
            }
            for (int i = 1; i <= n; ++i) {
                if (visl[i]) lx[i] -= val;
                if (visr[i]) {
                    ly[i] += val;
                } else {
                    slack[i] -= val;
                }
            }
            for (int i = 1; i <= n; ++i) {
                if (!visr[i] && !slack[i] && check(i)) {
                    return;
                }
            }
        }
    }
    int work() {
        fill(ansl.begin(), ansl.end(), -1);
        fill(ansr.begin(), ansr.end(), -1);
        fill(lx.begin(), lx.end(), 0);
        fill(ly.begin(), ly.end(), -1E18);
        for (int i = 1; i <= n; ++i) {
            for (int j = 1; j <= n; ++j) {
                ly[i] = max(ly[i], ver[j][i]);
            }
        }
        for (int i = 1; i <= n; ++i) bfs(i);
        int res = 0;
        for (int i = 1; i <= n; ++i) {
            res += ver[i][ansl[i]];
        }
        return res;
    }
    pair<vector<int>, vector<int>> answer(int x, int y) { // 获取方案 (0 代表无匹配)
        vector<int> left(x + 1), right(y + 1);
        for (int i = 1; i <= x; ++i) {
            left[i] = (ansl[i] <= y && hasEdge[i][ansl[i]] ? ansl[i] : 0);
        }
        for (int i = 1; i <= y; ++i) {
            right[i] = (ansr[i] <= x && hasEdge[ansr[i]][i] ? ansr[i] : 0);
        }
        return {left, right};
    }
};
```

先用 `MaxCostMatch G(max(n1, n2));` 初始化，再调用 `G.add(x, y, w);` 加原图边。调用 `G.work()` 得到原图的最大匹配权值和。随后调用 `auto res = G.answer(n1, n2);` 恢复方案。遍历 `res.first[1...n1]` 可输出每个左点匹配的右点，`res.second[1...n2]` 则给出每个右点匹配的左点，两侧都用 `0` 表示未匹配。 [UOJ #80 二分图最大权匹配](https://uoj.ac/problem/80)

### 二分图最大独立集（König 定理）

> **用途：** 求二分图中两两不相邻的点的最大数量。
>
> **复杂度：** 求大小的时间和空间复杂度取决于所用的最大匹配模板。恢复方案另需 $O(N+M)$ 时间和 $O(N)$ 额外空间，$N=n_1+n_2$，$M$ 是边数。

包含每条边至少一个端点的点集称为点覆盖。点覆盖的补集是独立集，独立集的补集也是点覆盖。由 König 定理，二分图的最小点覆盖大小等于最大匹配边数，因此**最大独立集大小等于总点数减去最大匹配边数**。

用本章的「二分图最大匹配」模板建好原图后，直接计算：

```c++
cout << n1 + n2 - G.work() << '\n';
```

**恢复方案。** 求出最大匹配后，从所有未匹配的左点出发，沿非匹配边从左到右、沿匹配边从右到左搜索。最大独立集由**访问过的左点**和**未访问过的右点**组成，它的补集就是一个最小点覆盖。

**点带权。** 若点权非负，最大权独立集的权值等于总点权减去最小权点覆盖的权值。用最小割求最小权点覆盖：源点向左点连边、右点向汇点连边，容量取对应点权；原图每条边从左点连向右点，容量取大于总点权的整数（如总点权加 $1$，须保证容量类型可表示）。答案为总点权减去最大流。

### 无源汇点的最小割问题 Stoer–Wagner

> 也称为全局最小割。定义补充（与《网络流》中的定义不同）：
> 
> **割**：是一个边集，去掉其中所有边能使一张网络流图不再连通（即分成两个子图）。

通过**递归**的方式来解决**无向正权图**上的全局最小割问题，算法复杂度 $\mathcal O(VE + V^{2}\log V)$ ，一般可近似看作 $\mathcal O(V^3)$ 。

```c++
struct StoerWagner {
    static constexpr int INF = 1e18;
    int n;
    vector<vector<int>> edge;
    StoerWagner(int n) {
        this->n = n;
        edge.resize(n + 1, vector<int>(n + 1));
    }
    void add(int x, int y, int w) {
        edge[x][y] += w;
        edge[y][x] += w;
    }
    bool connected() {
        int s = 0;
        for (int i = 1; i <= n; ++i) {
            for (int j = 1; j <= n; ++j) {
                if (edge[i][j]) {
                    s = i;
                    break;
                }
            }
            if (s) break;
        }
        if (!s) return n <= 1;
        vector<int> vis(n + 1);
        function<void(int)> dfs = [&](int x) {
            vis[x] = 1;
            for (int y = 1; y <= n; ++y) {
                if (edge[x][y] && !vis[y]) {
                    dfs(y);
                }
            }
        };
        dfs(s);
        for (int i = 1; i <= n; ++i) {
            if (!vis[i]) return false;
        }
        return true;
    }
    int work() {
        if (!connected()) return 0;
        vector<vector<int>> g = edge;
        vector<int> bin(n + 1);
        int minCut = INF, S = 1, T = 1;
        auto contract = [&]() -> int {
            vector<int> dis(n + 1), vis(n + 1);
            int cut = 0;
            for (int i = 1; i <= n; ++i) {
                int k = -1, maxc = -1;
                for (int j = 1; j <= n; ++j) {
                    if (!bin[j] && !vis[j] && dis[j] > maxc) {
                        k = j;
                        maxc = dis[j];
                    }
                }
                if (k == -1) return cut;
                S = T, T = k, cut = maxc;
                vis[k] = 1;
                for (int j = 1; j <= n; ++j) {
                    if (!bin[j] && !vis[j]) {
                        dis[j] += g[k][j];
                    }
                }
            }
            return cut;
        };
        for (int i = 1; i < n; ++i) {
            int val = contract();
            bin[T] = 1;
            minCut = min(minCut, val);
            if (!minCut) return 0;
            for (int j = 1; j <= n; ++j) {
                if (!bin[j]) {
                    g[S][j] += g[T][j];
                    g[j][S] += g[j][T];
                }
            }
        }
        return minCut;
    }
};
constexpr int StoerWagner::INF;
```

用法：先 `StoerWagner G(n);` ，再 `G.add(x, y, w);` 加无向正权边。调用 `G.work();` 返回全局最小割；若原图不连通，则返回 `0` 。

### 欧拉路径与回路（Hierholzer）

欧拉路径把每条边恰好走一次，起终点相同就是欧拉回路。两种图都要先忽略孤立点，把边暂时当成无向边检查连通。

- **有向图**：开放路径的起点出度多 1，终点入度多 1，其他点入度等于出度。回路要求所有点入度等于出度。
- **无向图**：开放路径恰有两个奇度点，分别是起点和终点。回路中所有点的度数都是偶数。

每次走当前点编号最小的未用邻边，走不动才把点加入答案，最后翻转答案。无向边的两个方向共用边号，走一条就把两份一起删掉。允许自环、重边。时间 $O(N+M\log(M+1))$，空间 $O(N+M)$。

```c++
struct EulerGraph {
    int n, m = 0;
    bool directed;
    using Edge = pair<int, int>; // 终点、边号
    vector<multiset<Edge>> ver;
    vector<vector<int>> undir;
    vector<int> deg, balance;
    EulerGraph(int n, bool directed)
        : n(n), directed(directed), ver(n + 1), undir(n + 1),
          deg(n + 1), balance(n + 1) {}
    void add(int x, int y) {
        ver[x].insert({y, ++m});
        if (!directed) ver[y].insert({x, m});
        undir[x].push_back(y);
        undir[y].push_back(x);
        ++deg[x], ++deg[y];
        ++balance[x], --balance[y];
    }
    int getStart() {
        for (int x = 1; x <= n; ++x)
            if (directed ? balance[x] == 1 : deg[x] % 2) return x;
        for (int x = 1; x <= n; ++x)
            if (deg[x]) return x;
        return 1;
    }
    bool connected() {
        vector<char> seen(n + 1);
        vector<int> q{getStart()};
        seen[q[0]] = 1;
        for (int i = 0; i < (int)q.size(); ++i)
            for (int y : undir[q[i]]) {
                if (seen[y]) continue;
                seen[y] = 1;
                q.push_back(y);
            }
        for (int x = 1; x <= n; ++x)
            if (deg[x] && !seen[x]) return false;
        return true;
    }
    bool hasEulerPath() {
        if (!connected()) return false;
        int plus = 0, minus = 0, odd = 0;
        for (int x = 1; x <= n; ++x) {
            odd += deg[x] % 2;
            plus += balance[x] == 1;
            minus += balance[x] == -1;
            if (directed && abs(balance[x]) > 1) return false;
        }
        if (directed) return plus == minus && plus <= 1;
        return odd == 0 || odd == 2;
    }
    vector<int> workVertices(int s) {
        if (s == -1) s = getStart();
        vector<int> path, stk{s};
        while (!stk.empty()) {
            int x = stk.back();
            if (ver[x].empty()) {
                path.push_back(x);
                stk.pop_back();
            } else {
                auto e = *ver[x].begin();
                ver[x].erase(ver[x].begin());
                int y = e.first;
                if (!directed) ver[y].erase(ver[y].find({x, e.second}));
                stk.push_back(y);
            }
        }
        reverse(path.begin(), path.end());
        return path;
    }
};

struct DirectedEulerGraph : EulerGraph {
    DirectedEulerGraph(int n) : EulerGraph(n, true) {}
    vector<int> work(int s = -1) { return workVertices(s); }
};

struct UndirectedEulerGraph : EulerGraph {
    UndirectedEulerGraph(int n) : EulerGraph(n, false) {}
    vector<pair<int, int>> work(int s = -1) {
        auto path = workVertices(s);
        vector<pair<int, int>> edges;
        for (int i = 1; i < (int)path.size(); ++i)
            edges.emplace_back(path[i - 1], path[i]);
        return edges;
    }
};
```

两种模板都用 `add(x,y)` 加边，先 `hasEulerPath()` 判断是否有解，再调用 `work()`。有向版返回点序列，无向版返回按走过的顺序排列的边。可以用 `work(s)` 指定合法起点，得到从该点出发的字典序最小方案。`work` 会消耗邻接表中的边。

### 差分约束

> **用途：** 给出一组可行势能或报告无解。
>
> **复杂度：** $O(NM+N)$ 时间，$O(N+M)$ 空间。
>
> **使用条件：** 用 add(u,v,w) 表示 $u-v\le w$。

给出一组包含 $m$ 个不等式，有 $n$ 个未知数的形如：$ \begin{cases} u_1-v_1\leq w_1 \\u_2-v_2 \leq w_2 \\ \cdots\\ u_m -v_m\leq w_m\end{cases}$的不等式组，求任意一组满足这个不等式组的解。下方使用 Bellman-Ford 式松弛判负环，复杂度 $\mathcal O(nm)$ 。[参考](https://www.luogu.com.cn/problem/P5960)

```c++
struct DifferenceConstraints {
    int n;
    vector<array<int, 3>> e;
    vector<int> dis;
    DifferenceConstraints(int n) {
        this->n = n;
        dis.resize(n + 1);
    }
    void add(int u, int v, int w) { // u - v <= w
        e.push_back({v, u, w});
    }
    bool work() {
        fill(dis.begin(), dis.end(), 0); // 超级源点向所有点连权值为 0 的边
        for (int i = 1; i <= n; ++i) {
            bool update = false;
            for (auto item : e) {
                auto u = get<0>(item);
                auto v = get<1>(item);
                auto w = get<2>(item);
                if (dis[v] > dis[u] + w) {
                    dis[v] = dis[u] + w;
                    update = true;
                    if (i == n) {
                        return false;
                    }
                }
            }
            if (!update) {
                break;
            }
        }
        return true;
    }
    int getVal(int x) {
        return dis[x];
    }
};
```

用法：先 `DifferenceConstraints G(n);` ，再对每个不等式 `u - v <= w` 调用 `G.add(u, v, w);`。调用 `G.work();` 后，若返回 `false` 表示无解；否则 `G.getVal(i)` 给出一组可行解。

### 2-Sat

#### 基础封装

基于 tarjan 缩点，时间复杂度为 $\mathcal O(N+M)$ 。注意下标从 $0$ 开始，返回任意一组可行解。

| 操作 | 含义 | 复杂度 | 参数范围 |
| --- | --- | --- | --- |
| add(u,f,v,g) | 加入一个析取子句 | 摊还 $O(1)$ | 两变量编号均在 $[0,N)$ |
| work() | 判可满足性并构造一组赋值 | $O(N+M)$ | 建图后调用 |
| answer() | 返回一组可行赋值 | $O(N)$ | work() 成功后调用 |
| uniqueAnswer() | 逐变量判断取值是否唯一 | $O(N(N+M))$ | work() 成功后调用 |

```c++
struct TwoSat {
    int n;
    vector<vector<int>> e;
    vector<bool> ans;
    TwoSat(int n) : n(n), e(2 * n), ans(n) {}
    void add(int u, bool f, int v, bool g) {
        e[2 * u + !f].push_back(2 * v + g);
        e[2 * v + !g].push_back(2 * u + f);
    }
    bool work() {
        vector<int> id(2 * n, -1), dfn(2 * n, -1), low(2 * n, -1);
        vector<int> stk;
        int now = 0, cnt = 0;
        auto tarjan = [&](auto self, int u) -> void {
            stk.push_back(u);
            dfn[u] = low[u] = now++;
            for (auto v : e[u]) {
                if (dfn[v] == -1) {
                    self(self, v);
                    low[u] = min(low[u], low[v]);
                } else if (id[v] == -1) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
            if (dfn[u] == low[u]) {
                int v;
                do {
                    v = stk.back();
                    stk.pop_back();
                    id[v] = cnt;
                } while (v != u);
                ++cnt;
            }
        };
        for (int i = 0; i < 2 * n; ++i) {
            if (dfn[i] == -1) {
                tarjan(tarjan, i);
            }
        }
        for (int i = 0; i < n; ++i) {
            if (id[2 * i] == id[2 * i + 1]) return false;
            ans[i] = id[2 * i] > id[2 * i + 1];
        }
        return true;
    }
    vector<bool> answer() {
        return ans;
    }
    bool check(int x, int y) {
        vector<int> vis(2 * n);
        auto dfs = [&](auto self, int u) -> void {
            vis[u] = 1;
            for (auto v : e[u]) {
                if (vis[v]) continue;
                self(self, v);
            }
        };
        dfs(dfs, x);
        return vis[y];
    }
    vector<int> uniqueAnswer() {
        vector<int> res(n, -1);
        for (int i = 0; i < n; ++i) {
            if (check(2 * i, 2 * i + 1)) {
                res[i] = 1;
            } else if (check(2 * i + 1, 2 * i)) {
                res[i] = 0;
            }
        }
        return res;
    }
};
```

用法：先 `TwoSat G(n);` ，其中每个变量下标范围为 `[0, n - 1]`。调用 `G.add(u, f, v, g);` 表示加入子句 `(u == f) or (v == g)`；调用 `G.work();` 判断是否有解，若有解则可通过 `G.answer()` 取得一组可行布尔赋值。若题目要求“答案不唯一时不输出”，则继续调用 `G.uniqueAnswer()`：返回值中 `0/1` 表示该变量被唯一确定，`-1` 表示该变量取值不唯一。

#### 答案不唯一时不输出

在运行后针对每一个点进行一次 dfs，时间复杂度为 $\mathcal O(N(N+M))$ ，当且仅当答案唯一时才输出，否则输出 `?` 替代。

```c++
auto res = sat.uniqueAnswer();
for (int i = 0; i < n; i++) {
    if (res[i] == -1) {
        cout << "? ";
    } else {
        cout << res[i] << " ";
    }
}
```
