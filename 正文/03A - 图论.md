## 第三章：图论

### 常见概念

> oriented graph：有向图
> 
> bidirectional edges：双向边

平面图：若能将无向图 $G=(V,E)$ 画在平面上使得任意两条无重合顶点的边不相交，则称 $G$ 是平面图。

无向正权图上某一点的偏心距：记为 $ecc(u) = \max \big\{ dist(u, v) \big\}$ ，即以这个点为源，到其他点的**所有最短路的最大值**。如下图 $A$ 点，$ecc(A)$ 即为 $12$ 。

图的直径：定义为 $d = \max \big\{ ecc(u) \big\}$ ，即**最大的偏心距**，亦可以简化为图中最远的一对点的距离。

图的中心：定义为 $arg=\min \big\{ ecc(u)\big\}$ ，即**偏心距最小的点**。如下图，图的中心即为 $B$ 点。

图的绝对中心：可以定义在边上的图的中心。

图的半径：图的半径不同于圆的半径，其不等于直径的一半（但对于绝对中心定义上的直径而言是一半）。定义为 $r = \min \big\{ ecc(u) \big\}$ ，即**中心的偏心距**。计算方式：使用全源最短路，计算出所有点的偏心距，再加以计算。

### 单源最短路径（SSSP问题）

#### （正权稀疏图）动态数组存图+Dijkstra 算法

使用优先队列优化，以 $\mathcal O(M\log N)$ 的复杂度计算。

```c++
struct Dijkstra {
    static const int INF = 1E18;
    int n;
    vector<vector<pair<int, int>>> ver;
    vector<int> dis, vis;
    Dijkstra(int n) {
        this->n = n;
        ver.resize(n + 1);
        dis.resize(n + 1);
        vis.resize(n + 1);
    }
    void add(int x, int y, int w) { // 如果是无向图，再补一条 add(y, x, w)
        ver[x].push_back({y, w});
    }
    void init() {
        fill(dis.begin(), dis.end(), INF);
        fill(vis.begin(), vis.end(), 0);
    }
    void work(int s = 1) {
        init();
        using PII = pair<int, int>;
        priority_queue<PII, vector<PII>, greater<PII>> q;
        q.emplace(0, s);
        dis[s] = 0;
        while (!q.empty()) {
            int x = q.top().second;
            q.pop();
            if (vis[x]) continue;
            vis[x] = 1;
            for (auto [y, w] : ver[x]) {
                if (dis[y] > dis[x] + w) {
                    dis[y] = dis[x] + w;
                    q.emplace(dis[y], y);
                }
            }
        }
    }
    int getDis(int x) {
        return dis[x];
    }
};
```

用法：先 `Dijkstra G(n);` ，然后反复 `G.add(x, y, w);` 加边；若是无向图就双向加边。跑单源最短路时调用 `G.work(s);` ，查询点 `x` 到源点的最短距离时调用 `G.getDis(x)` 。

#### （负权图、判负环）Bellman-ford 算法

使用结构体存边（该算法无需存图），以 $\mathcal{O} (NM)$ 的复杂度计算。

```c++
struct BellmanFord {
    static const int INF = 1E18;
    int n;
    vector<tuple<int, int, int>> ver;
    vector<int> dis, chk;
    BellmanFord(int n) {
        this->n = n;
        dis.resize(n + 1);
        chk.resize(n + 1);
    }
    void add(int x, int y, int w) {
        ver.push_back({x, y, w});
    }
    void init() {
        fill(dis.begin(), dis.end(), INF);
        fill(chk.begin(), chk.end(), 0);
    }
    void work(int s = 1) {
        init();
        dis[s] = 0;
        for (int i = 1; i <= 2 * n; ++i) { // 双倍松弛，获取负环信息
            vector<int> backup = dis;
            for (auto [x, y, w] : ver) {
                if (backup[x] >= INF / 2) continue;
                chk[y] |= (i > n && backup[x] + w < dis[y]);
                dis[y] = min(dis[y], backup[x] + w);
            }
        }
    }
    int getDis(int x) {
        return dis[x];
    }
    bool cantReach(int x) {
        return dis[x] >= INF / 2;
    }
    bool inNegLoop(int x) {
        return chk[x];
    }
};
```

用法：先 `BellmanFord G(n);` ，再 `G.add(x, y, w);` 加边。调用 `G.work(s);` 后，`G.getDis(x)` 表示源点到 `x` 的最短距离；若 `G.cantReach(x)` 为真则不可达，若 `G.inNegLoop(x)` 为真则说明该点受到负环影响。

#### （负权图）SPFA 算法

以 $\mathcal{O}(KM)$ 的复杂度计算，其中 $K$ 虽然为常数，但是可以通过特殊的构造退化成接近 $N$ ，需要注意被卡。

```c++
struct SPFA {
    static const int INF = 1E18;
    int n;
    vector<vector<pair<int, int>>> ver;
    vector<int> dis, vis;
    SPFA(int n) {
        this->n = n;
        ver.resize(n + 1);
        dis.resize(n + 1);
        vis.resize(n + 1);
    }
    void add(int x, int y, int w) {
        ver[x].push_back({y, w});
    }
    void init() {
        fill(dis.begin(), dis.end(), INF);
        fill(vis.begin(), vis.end(), 0);
    }
    void work(int s = 1) {
        init();
        queue<int> q;
        q.push(s);
        dis[s] = 0;
        vis[s] = 1;
        while (!q.empty()) {
            int x = q.front();
            q.pop();
            vis[x] = 0;
            for (auto [y, w] : ver[x]) {
                if (dis[y] > dis[x] + w) {
                    dis[y] = dis[x] + w;
                    if (!vis[y]) {
                        q.push(y);
                        vis[y] = 1;
                    }
                }
            }
        }
    }
    int getDis(int x) {
        return dis[x];
    }
    bool cantReach(int x) {
        return dis[x] >= INF / 2;
    }
};
```

用法：先 `SPFA G(n);` ，再 `G.add(x, y, w);` 加边。调用 `G.work(s);` 后，`G.getDis(x)` 表示源点到 `x` 的最短距离；若 `G.cantReach(x)` 为真则表示不可达。

### 多源汇最短路（APSP问题）

使用邻接矩阵存图，可以处理负权边，以 $\mathcal{O}(N^3)$ 的复杂度计算。**注意，这里建立的是单向边，计算双向边需要额外加边**。

```c++
struct Floyd {
    static const int INF = 1E18;
    int n;
    vector<vector<int>> dis;
    Floyd(int n) {
        this->n = n;
        dis.resize(n + 1, vector<int>(n + 1, INF));
        for (int i = 1; i <= n; ++i) {
            dis[i][i] = 0;
        }
    }
    void init() {
        for (int i = 1; i <= n; ++i) {
            fill(dis[i].begin(), dis[i].end(), INF);
            dis[i][i] = 0;
        }
    }
    void add(int x, int y, int w) { // 如果是无向图，再补一条 add(y, x, w)
        dis[x][y] = min(dis[x][y], w);
    }
    void work() {
        for (int k = 1; k <= n; ++k) {
            for (int i = 1; i <= n; ++i) {
                for (int j = 1; j <= n; ++j) {
                    if (dis[i][k] >= INF / 2 || dis[k][j] >= INF / 2) continue;
                    dis[i][j] = min(dis[i][j], dis[i][k] + dis[k][j]);
                }
            }
        }
    }
    int getDis(int x, int y) {
        return dis[x][y];
    }
    bool cantReach(int x, int y) {
        return dis[x][y] >= INF / 2;
    }
};
```

用法：先 `Floyd G(n);` ，再 `G.add(x, y, w);` 加边；若是无向图就双向加边。调用 `G.work();` 后，`G.getDis(x, y)` 表示 `x` 到 `y` 的最短距离；若 `G.cantReach(x, y)` 为真则表示不可达。

### 最小生成树（MST问题）

#### （稠密图）Prim算法

使用邻接矩阵存图，以 $\mathcal{O}(N^2+M)$ 的复杂度计算，思想与 $\tt djikstra$ 基本一致。

```c++
struct Prim {
    static const int INF = 1E18;
    int n;
    vector<vector<int>> g;
    vector<int> dis, vis;
    Prim(int n) {
        this->n = n;
        g.resize(n + 1, vector<int>(n + 1, INF));
        dis.resize(n + 1);
        vis.resize(n + 1);
        for (int i = 1; i <= n; ++i) {
            g[i][i] = 0;
        }
    }
    void init() {
        fill(dis.begin(), dis.end(), INF);
        fill(vis.begin(), vis.end(), 0);
    }
    void add(int x, int y, int w) {
        g[x][y] = g[y][x] = min(g[x][y], w);
    }
    int work() {
        init();
        int ans = 0;
        for (int i = 0; i < n; ++i) {
            int t = -1;
            for (int j = 1; j <= n; ++j) {
                if (!vis[j] && (t == -1 || dis[j] < dis[t])) {
                    t = j;
                }
            }
            vis[t] = 1;
            if (i && dis[t] >= INF / 2) return INF;
            if (i) ans += dis[t];
            for (int j = 1; j <= n; ++j) {
                dis[j] = min(dis[j], g[t][j]);
            }
        }
        return ans;
    }
};
```

用法：先 `Prim G(n);` ，再 `G.add(x, y, w);` 加无向边。调用 `G.work();` 返回最小生成树边权和；若返回值大于等于 `Prim::INF / 2` 则说明原图不连通，无法生成最小生成树。

#### （稀疏图）Kruskal算法

平均时间复杂度为 $\mathcal{O}(M\log M)$ ，简化了并查集。

```c++
struct DSU {
    vector<int> fa;
    DSU(int n) : fa(n + 1) {
        iota(fa.begin(), fa.end(), 0);
    }
    int get(int x) {
        while (x != fa[x]) {
            x = fa[x] = fa[fa[x]];
        }
        return x;
    }
    bool merge(int x, int y) { // 设x是y的祖先
        x = get(x), y = get(y);
        if (x == y) return false;
        fa[y] = x;
        return true;
    }
    bool same(int x, int y) {
        return get(x) == get(y);
    }
};
struct Kruskal {
    static const int INF = 1E18;
    using TII = tuple<int, int, int>;
    int n;
    vector<TII> ver;
    Kruskal(int n) {
        this->n = n;
    }
    void add(int x, int y, int w) {
        ver.push_back({w, x, y}); // 注意顺序
    }
    int work() {
        DSU dsu(n);
        int ans = 0, cnt = 0;
        sort(ver.begin(), ver.end());
        for (auto [w, x, y] : ver) {
            if (dsu.same(x, y)) continue;
            dsu.merge(x, y);
            ans += w;
            cnt++;
        }
        if (cnt != n - 1) return INF;
        return ans;
    }
};
```

用法：先 `Kruskal G(n);` ，再 `G.add(x, y, w);` 加无向边。调用 `G.work();` 返回最小生成树边权和；若返回值大于等于 `Kruskal::INF / 2` 则说明原图不连通。

### 缩点（Tarjan 算法）

#### （有向图）强连通分量缩点

强连通分量缩点后的图称为 SCC。以 $\mathcal O (N + M)$ 的复杂度完成上述全部操作。

> 性质：缩点后的图拥有拓扑序 $color_{cnt}, color_{cnt-1},…,1$ ，可以不需再另跑一遍 $\tt topsort$ ；缩点后的图是一张有向无环图（ $\tt DAG$ 、拓扑图）。

```c++
struct SCC {
    int n, now, cnt;
    vector<vector<int>> ver;
    vector<int> dfn, low, col, S;

    SCC(int n) : n(n), ver(n + 1), low(n + 1) {
        dfn.resize(n + 1, -1);
        col.resize(n + 1, -1);
        now = cnt = 0;
    }
    void add(int x, int y) {
        ver[x].push_back(y);
    }
    void tarjan(int x) {
        dfn[x] = low[x] = now++;
        S.push_back(x);
        for (auto y : ver[x]) {
            if (dfn[y] == -1) {
                tarjan(y);
                low[x] = min(low[x], low[y]);
            } else if (col[y] == -1) {
                low[x] = min(low[x], dfn[y]);
            }
        }
        if (dfn[x] == low[x]) {
            int pre;
            cnt++;
            do {
                pre = S.back();
                col[pre] = cnt;
                S.pop_back();
            } while (pre != x);
        }
    }
    auto work() { // [cnt 新图的顶点数量]
        for (int i = 1; i <= n; i++) { // 避免图不连通
            if (dfn[i] == -1) {
                tarjan(i);
            }
        }

        vector<int> siz(cnt + 1); // siz 每个 scc 中点的数量
        vector<vector<int>> adj(cnt + 1);
        for (int i = 1; i <= n; i++) {
            siz[col[i]]++;
            for (auto j : ver[i]) {
                int x = col[i], y = col[j];
                if (x != y) {
                    adj[x].push_back(y);
                }
            }
        }
        return tuple{cnt, adj, col, siz};
    }
};
```

用法：先 `SCC G(n);` ，再 `G.add(x, y);` 建有向边。调用 `auto [cnt, adj, col, siz] = G.work();` 后，`cnt` 是缩点后新图点数，`adj` 是新图邻接表，`col[i]` 表示原图点 `i` 属于哪个强连通分量，`siz[i]` 表示第 `i` 个强连通分量大小。

#### （无向图）割边缩点

割边缩点后的图称为边双连通图 (E-DCC)，该模板可以在  $\mathcal O (N + M)$ 复杂度内求解图中全部割边、划分边双（颜色相同的点位于同一个边双连通分量中）。

> 割边（桥）：将某边 $e$ 删去后，原图分成两个以上不相连的子图，称 $e$ 为图的割边。
> 
> 边双连通：在一张连通的无向图中，对于两个点 $u$ 和 $v$，删去任何一条边（只能删去一条）它们依旧连通，则称 $u$ 和 $v$ 边双连通。一个图如果不存在割边，则它是一个边双连通图。
> 
> 性质补充：对于一个边双，删去任意边后依旧联通；对于边双中的任意两点，一定存在两条不相交的路径连接这两个点（路径上可以有公共点，但是没有公共边）。

```c++
struct EDCC {
    int n, m, now, cnt;
    vector<vector<array<int, 2>>> ver;
    vector<int> dfn, low, col, S;
    set<array<int, 2>> bridge, direct; // 如果不需要，删除这一部分可以得到一些时间上的优化

    EDCC(int n) : n(n), low(n + 1), ver(n + 1), dfn(n + 1), col(n + 1) {
        m = now = cnt = 0;
    }
    void add(int x, int y) { // 和 scc 相比多了一条连边
        ver[x].push_back({y, m});
        ver[y].push_back({x, m++});
    }
    void tarjan(int x, int fa) {
        dfn[x] = low[x] = ++now;
        S.push_back(x);
        for (auto &[y, id] : ver[x]) {
            if (!dfn[y]) {
                direct.insert({x, y});
                tarjan(y, id);
                low[x] = min(low[x], low[y]);
                if (dfn[x] < low[y]) {
                    bridge.insert({x, y});
                }
            } else if (id != fa && dfn[y] < dfn[x]) {
                direct.insert({x, y});
                low[x] = min(low[x], dfn[y]);
            }
        }
        if (dfn[x] == low[x]) {
            int pre;
            cnt++;
            do {
                pre = S.back();
                col[pre] = cnt;
                S.pop_back();
            } while (pre != x);
        }
    }
    auto work() {
        for (int i = 1; i <= n; i++) { // 避免图不连通
            if (!dfn[i]) {
                tarjan(i, 0);
            }
        }
        /**
         * @param cnt 新图的顶点数量, adj 新图, col 旧图节点对应的新图节点
         * @param siz 旧图每一个边双中点的数量
         * @param bridge 全部割边, direct 非割边定向
         */
        vector<int> siz(cnt + 1);
        vector<vector<int>> adj(cnt + 1);
        for (int i = 1; i <= n; i++) {
            siz[col[i]]++;
            for (auto &[j, id] : ver[i]) {
                int x = col[i], y = col[j];
                if (x != y) {
                    adj[x].push_back(y);
                }
            }
        }
        return tuple{cnt, adj, col, siz};
    }
};
```

用法：先 `EDCC G(n);` ，再 `G.add(x, y);` 加无向边。调用 `auto [cnt, adj, col, siz] = G.work();` 后，`cnt` 是边双缩点后的新图点数，`adj` 是新图邻接表，`col[i]` 表示原图点 `i` 属于哪个边双连通分量，`siz[i]` 表示第 `i` 个边双的点数；若需要桥边信息，可直接查看 `G.bridge` 。

#### （无向图）割点缩点

割点缩点后的图称为点双连通图 (V-DCC)，该模板可以在  $\mathcal O (N + M)$ 复杂度内求解图中全部割点、划分点双（颜色相同的点位于同一个点双连通分量中）。

> 割点（割顶）：将与某点 $i$ 连接的所有边删去后，原图分成两个以上不相连的子图，称 $i$ 为图的割点。
> 
> 点双连通：在一张连通的无向图中，对于两个点 $u$ 和 $v$，删去任何一个点（只能删去一个，且不能删 $u$ 和 $v$自己）它们依旧连通，则称 $u$ 和 $v$ 边双连通。如果一个图不存在割点，那么它是一个点双连通图。
> 
> 性质补充：每一个割点至少属于两个点双。

```c++
struct V_DCC {
    int n;
    vector<vector<int>> ver, col;
    vector<int> dfn, low, S;
    vector<int> pointId;
    int now, cnt;
    vector<bool> point; // 记录是否为割点

    V_DCC(int n) : n(n) {
        ver.resize(n + 1);
        dfn.resize(n + 1);
        low.resize(n + 1);
        col.resize(2 * n + 1);
        pointId.resize(n + 1);
        point.resize(n + 1);
        S.clear();
        cnt = now = 0;
    }
    void add(int x, int y) {
        if (x == y) return; // 手动去除重边
        ver[x].push_back(y);
        ver[y].push_back(x);
    }
    void tarjan(int x, int root) {
        low[x] = dfn[x] = ++now;
        S.push_back(x);
        if (x == root && !ver[x].size()) { // 特判孤立点
            ++cnt;
            col[cnt].push_back(x);
            return;
        }

        int flag = 0;
        for (auto y : ver[x]) {
            if (!dfn[y]) {
                tarjan(y, root);
                low[x] = min(low[x], low[y]);
                if (dfn[x] <= low[y]) {
                    flag++;
                    if (x != root || flag > 1) {
                        point[x] = true; // 标记为割点
                    }
                    int pre = 0;
                    cnt++;
                    do {
                        pre = S.back();
                        col[cnt].push_back(pre);
                        S.pop_back();
                    } while (pre != y);
                    col[cnt].push_back(x);
                }
            } else {
                low[x] = min(low[x], dfn[y]);
            }
        }
    }
    pair<int, vector<vector<int>>> rebuild() { // [新图的顶点数量, 新图]
        work();
        fill(pointId.begin(), pointId.end(), 0);
        int tot = cnt;
        for (int i = 1; i <= n; ++i) {
            if (point[i]) {
                pointId[i] = ++tot;
            }
        }
        vector<vector<int>> adj(tot + 1);
        for (int i = 1; i <= cnt; i++) {
            if (!col[i].size()) { // 注意，孤立点也是 V-DCC
                continue;
            }
            for (auto j : col[i]) {
                if (point[j]) { // 如果 j 是割点
                    adj[i].push_back(pointId[j]);
                    adj[pointId[j]].push_back(i);
                }
            }
        }
        return {tot, adj};
    }
    void work() {
        for (int i = 1; i <= n; ++i) { // 避免图不连通
            if (!dfn[i]) {
                tarjan(i, i);
            }
        }
    }
};
```

用法：先 `V_DCC G(n);` ，再 `G.add(x, y);` 加无向边。调用 `G.work();` 后，`G.point[i]` 表示点 `i` 是否为割点，`G.col[i]` 中保存每个点双连通分量包含的点；若需要构造点双缩点图，可继续调用 `auto [tot, adj] = G.rebuild();`，其中 `tot` 是圆方树总点数，原点双编号仍为 `1...G.cnt`，原图中的割点 `x` 对应新图编号 `G.pointId[x]` 。

### 染色法判定二分图 (dfs算法)

判断一张图能否被二分染色。

```c++
struct BipartiteGraph {
    int n;
    vector<vector<int>> ver;
    vector<int> color;
    BipartiteGraph(int n) {
        this->n = n;
        ver.resize(n + 1);
        color.resize(n + 1);
    }
    void add(int x, int y) {
        ver[x].push_back(y);
        ver[y].push_back(x);
    }
    bool dfs(int x, int type) {
        color[x] = type;
        for (auto y : ver[x]) {
            if (color[y] == type) {
                return false;
            }
            if (color[y]) continue;
            if (!dfs(y, 3 - type)) {
                return false;
            }
        }
        return true;
    }
    bool work() {
        fill(color.begin(), color.end(), 0);
        for (int i = 1; i <= n; ++i) {
            if (color[i]) continue;
            if (!dfs(i, 1)) {
                return false;
            }
        }
        return true;
    }
};
```

用法：先 `BipartiteGraph G(n);` ，再 `G.add(x, y);` 加无向边。调用 `G.work();` 判断整张图是否为二分图；若需要具体染色方案，可直接查看 `G.color[i]` 的值（`1/2` 表示两种颜色）。

### 链式前向星建图与搜索

很少使用这种建图法。$\tt dfs$ ：标准复杂度为 $\mathcal O(N+M)$。节点子节点的数量包含它自己（至少为 $1$），深度从 $0$ 开始（根节点深度为 $0$）。$\tt bfs$ ：深度从 $1$ 开始（根节点深度为 $1$）。$\tt topsort$ ：有向无环图（包括非联通）才拥有完整的拓扑序列（故该算法也可用于判断图中是否存在环）。每次找到入度为 $0$ 的点并将其放入待查找队列。

```c++
struct ForwardStarGraph {
    int n, tot;
    vector<int> h, ver, ne, deg, vis, siz, dep, bfsDep;
    vector<int> dfsOrder;
    ForwardStarGraph(int n, int m) {
        this->n = n;
        tot = 0;
        h.resize(n + 1);
        ver.resize(m + 1);
        ne.resize(m + 1);
        deg.resize(n + 1);
        vis.resize(n + 1);
        siz.resize(n + 1);
        dep.resize(n + 1);
        bfsDep.resize(n + 1);
    }
    void init() {
        tot = 0;
        fill(h.begin(), h.end(), 0);
        fill(deg.begin(), deg.end(), 0);
        fill(vis.begin(), vis.end(), 0);
        fill(siz.begin(), siz.end(), 0);
        fill(dep.begin(), dep.end(), 0);
        fill(bfsDep.begin(), bfsDep.end(), 0);
        dfsOrder.clear();
    }
    void add(int x, int y) {
        ver[++tot] = y;
        ne[tot] = h[x];
        h[x] = tot;
        ++deg[y];
    }
    void dfs(int root) {
        fill(vis.begin(), vis.end(), 0);
        fill(siz.begin(), siz.end(), 0);
        fill(dep.begin(), dep.end(), 0);
        dfsOrder.clear();
        function<void(int)> solve = [&](int x) {
            dfsOrder.push_back(x); // DFS 序进入时刻
            siz[x] = vis[x] = 1;
            for (int i = h[x]; i; i = ne[i]) {
                int y = ver[i];
                if (vis[y]) continue;
                dep[y] = dep[x] + 1;
                solve(y);
                siz[x] += siz[y];
            }
            dfsOrder.push_back(x); // DFS 序离开时刻
        };
        solve(root);
    }
    void bfs(int s) {
        fill(bfsDep.begin(), bfsDep.end(), 0);
        queue<int> q;
        q.push(s);
        bfsDep[s] = 1;
        while (!q.empty()) {
            int x = q.front();
            q.pop();
            for (int i = h[x]; i; i = ne[i]) {
                int y = ver[i];
                if (bfsDep[y]) continue;
                bfsDep[y] = bfsDep[x] + 1;
                q.push(y);
            }
        }
    }
    pair<bool, vector<int>> topsort() {
        vector<int> in = deg, ans;
        queue<int> q;
        for (int i = 1; i <= n; ++i) {
            if (in[i] == 0) q.push(i);
        }
        while (!q.empty()) {
            int x = q.front();
            q.pop();
            ans.push_back(x);
            for (int i = h[x]; i; i = ne[i]) {
                int y = ver[i];
                --in[y];
                if (in[y] == 0) q.push(y);
            }
        }
        return {ans.size() == n, ans};
    }
};
```

用法：先 `ForwardStarGraph G(n, m);` 预留边数容量，再 `G.add(x, y);` 建边。`G.dfs(root);` 后可通过 `G.dfsOrder`、`G.siz[x]`、`G.dep[x]` 读取 DFS 相关信息；`G.bfs(s);` 后 `G.bfsDep[x]` 表示 BFS 深度；`auto [ok, ord] = G.topsort();` 用于获取拓扑序。

### 一般图最大匹配（带花树算法）

与二分图匹配的差别在于图中可能存在奇环，时间复杂度与边的数量无关，为 $\mathcal O(N^3)$ 。下方模板编号从 $0$ 开始，例题为 [UOJ #79. 一般图最大匹配](https://uoj.ac/problem/79) 。

```c++
struct GeneralMatching {
    int n;
    vector<vector<int>> e;
    GeneralMatching(int n) : n(n), e(n) {}
    void add(int u, int v) {
        e[u].push_back(v);
        e[v].push_back(u);
    }
    pair<int, vector<int>> work() {
        vector<int> match(n, -1), vis(n), link(n), f(n), dep(n);
        auto find = [&](int u) {
            while (f[u] != u) u = f[u] = f[f[u]];
            return u;
        };
        auto lca = [&](int u, int v) {
            u = find(u), v = find(v);
            while (u != v) {
                if (dep[u] < dep[v]) swap(u, v);
                u = find(link[match[u]]);
            }
            return u;
        };
        queue<int> q;
        auto blossom = [&](int u, int v, int p) {
            while (find(u) != p) {
                link[u] = v;
                v = match[u];
                if (vis[v] == 0) {
                    vis[v] = 1;
                    q.push(v);
                }
                f[u] = f[v] = p;
                u = link[v];
            }
        };
        auto augment = [&](int u) {
            while (!q.empty()) q.pop();
            iota(f.begin(), f.end(), 0);
            fill(vis.begin(), vis.end(), -1);
            q.push(u);
            vis[u] = 1;
            dep[u] = 0;
            while (!q.empty()) {
                int u = q.front();
                q.pop();
                for (auto v : e[u]) {
                    if (vis[v] == -1) {
                        vis[v] = 0;
                        link[v] = u;
                        dep[v] = dep[u] + 1;
                        if (match[v] == -1) {
                            for (int x = v, y = u, temp; y != -1;
                                 x = temp, y = x == -1 ? -1 : link[x]) {
                                temp = match[y];
                                match[x] = y;
                                match[y] = x;
                            }
                            return;
                        }
                        vis[match[v]] = 1;
                        dep[match[v]] = dep[u] + 2;
                        q.push(match[v]);
                    } else if (vis[v] == 1 && find(v) != find(u)) {
                        int p = lca(u, v);
                        blossom(u, v, p);
                        blossom(v, u, p);
                    }
                }
            }
        };
        auto greedy = [&]() {
            for (int u = 0; u < n; ++u) {
                if (match[u] != -1) continue;
                for (auto v : e[u]) {
                    if (match[v] == -1) {
                        match[u] = v;
                        match[v] = u;
                        break;
                    }
                }
            }
        };
        greedy();
        for (int u = 0; u < n; u++) {
            if (match[u] == -1) {
                augment(u);
            }
        }
        int ans = 0;
        for (int u = 0; u < n; u++) {
            if (match[u] != -1) {
                ans++;
            }
        }
        return {ans / 2, match};
    }
};
```

用法：先 `GeneralMatching G(n);` ，注意这个模板点编号是 `0-indexed`。调用 `G.add(u, v);` 加无向边，`auto [cnt, match] = G.work();` 后，`cnt` 是最大匹配数，`match[i]` 表示与点 `i` 匹配的点编号，若为 `-1` 表示未匹配。

### 一般图最大权匹配（带权带花树算法）

下方模板编号从 $1$ 开始，复杂度为 $\mathcal O(N^3)$ 。

```c++
struct GeneralWeightedMatching {
    static const int MAXN = 403 * 2; // 两倍点数
    using T = int;
    static const T INF = numeric_limits<int>::max() >> 1;
    struct Q {
        int u, v;
        T w;
    };
    vector<vector<Q>> e;
    vector<T> lab;
    int n, m, id, h, t;
    vector<int> lk, sl, st, f, s, ed, q;
    vector<vector<int>> b, p;
    vector<tuple<int, int, int>> edges;
    vector<array<int, 2>> matchAns;
#define dvd(x) (lab[x.u] + lab[x.v] - e[x.u][x.v].w * 2)
#define FOR(i, b) for (int i = 1; i <= (int)(b); i++)
#define ALL(x) (x).begin(), (x).end()
    GeneralWeightedMatching(int n = 0) {
        init(n);
    }
    void init(int n) {
        this->n = n;
        m = id = h = t = 0;
        edges.clear();
        matchAns.clear();
        e.assign(MAXN, vector<Q>(MAXN));
        lab.assign(MAXN, 0);
        lk.assign(MAXN, 0);
        sl.assign(MAXN, 0);
        st.assign(MAXN, 0);
        f.assign(MAXN, 0);
        b.assign(MAXN, vector<int>(MAXN));
        s.assign(MAXN, 0);
        ed.assign(MAXN, 0);
        q.assign(MAXN, 0);
        p.assign(MAXN, {});
    }
    void add(int u, int v, int w) {
        edges.push_back({u, v, w});
    }
    void upd(int u, int v) {
        if (!sl[v] || dvd(e[u][v]) < dvd(e[sl[v]][v])) {
            sl[v] = u;
        }
    }
    void ss(int v) {
        sl[v] = 0;
        FOR(u, n) {
            if (e[u][v].w > 0 && st[u] != v && !s[st[u]]) {
                upd(u, v);
            }
        }
    }
    void ins(int u) {
        if (u <= n) { q[++t] = u; }
        else {
            for (int v : p[u]) ins(v);
        }
    }
    void mdf(int u, int w) {
        st[u] = w;
        if (u > n) {
            for (int v : p[u]) mdf(v, w);
        }
    }
    int gr(int u, int v) {
        v = find(ALL(p[u]), v) - p[u].begin();
        if (v & 1) {
            reverse(1 + ALL(p[u]));
            return (int)p[u].size() - v;
        }
        return v;
    }
    void stm(int u, int v) {
        lk[u] = e[u][v].v;
        if (u <= n) return;
        Q w = e[u][v];
        int x = b[u][w.u], y = gr(u, x);
        for (int i = 0; i < y; i++) {
            stm(p[u][i], p[u][i ^ 1]);
        }
        stm(x, v);
        rotate(p[u].begin(), y + ALL(p[u]));
    }
    void aug(int u, int v) {
        int w = st[lk[u]];
        stm(u, v);
        if (!w) return;
        stm(w, st[f[w]]), aug(st[f[w]], w);
    }
    int lca(int u, int v) {
        for (++id; u | v; swap(u, v)) {
            if (!u) continue;
            if (ed[u] == id) return u;
            ed[u] = id;
            if (u = st[lk[u]]) u = st[f[u]];
        }
        return 0;
    }
    void blossomAdd(int u, int a, int v) {
        int x = n + 1, i, j;
        while (x <= m && st[x]) ++x;
        if (x > m) ++m;
        lab[x] = s[x] = st[x] = 0;
        lk[x] = lk[a];
        p[x].clear();
        p[x].push_back(a);
        for (i = u; i != a; i = st[f[j]]) {
            p[x].push_back(i);
            p[x].push_back(j = st[lk[i]]);
            ins(j);
        }
        reverse(1 + ALL(p[x]));
        for (i = v; i != a; i = st[f[j]]) { // 复制，只需改循环
            p[x].push_back(i);
            p[x].push_back(j = st[lk[i]]);
            ins(j);
        }
        mdf(x, x);
        FOR(i, m) {
            e[x][i].w = e[i][x].w = 0;
        }
        fill(b[x].begin() + 1, b[x].begin() + n + 1, 0);
        for (int u : p[x]) {
            FOR(v, m) {
                if (!e[x][v].w || dvd(e[u][v]) < dvd(e[x][v])) {
                    e[x][v] = e[u][v], e[v][x] = e[v][u];
                }
            }
            FOR(v, n) {
                if (b[u][v]) { b[x][v] = u; }
            }
        }
        ss(x);
    }
    void ex(int u) {
        for (int x : p[u]) mdf(x, x);
        int a = b[u][e[u][f[u]].u], r = gr(u, a);
        for (int i = 0; i < r; i += 2) {
            int x = p[u][i], y = p[u][i + 1];
            f[x] = e[y][x].u;
            s[x] = 1;
            s[y] = sl[x] = 0;
            ss(y), ins(y);
        }
        s[a] = 1, f[a] = f[u];
        for (int i = r + 1; i < p[u].size(); i++) {
            s[p[u][i]] = -1;
            ss(p[u][i]);
        }
        st[u] = 0;
    }
    bool on(const Q &e) {
        int u = st[e.u], v = st[e.v];
        if (s[v] == -1) {
            f[v] = e.u, s[v] = 1;
            int a = st[lk[v]];
            sl[v] = sl[a] = s[a] = 0;
            ins(a);
        } else if (!s[v]) {
            int a = lca(u, v);
            if (!a) {
                return aug(u, v), aug(v, u), 1;
            } else {
                blossomAdd(u, a, v);
            }
        }
        return 0;
    }
    bool bfs() {
        fill(s.begin() + 1, s.begin() + m + 1, -1);
        fill(sl.begin() + 1, sl.begin() + m + 1, 0);
        h = 1, t = 0;
        FOR(i, m) {
            if (st[i] == i && !lk[i]) {
                f[i] = s[i] = 0;
                ins(i);
            }
        }
        if (h > t) return 0;
        while (1) {
            while (h <= t) {
                int u = q[h++];
                if (s[st[u]] == 1) continue;
                FOR(v, n) {
                    if (e[u][v].w > 0 && st[u] != st[v]) {
                        if (dvd(e[u][v])) upd(u, st[v]);
                        else if (on(e[u][v])) return 1;
                    }
                }
            }
            T x = INF;
            for (int i = n + 1; i <= m; i++) {
                if (st[i] == i && s[i] == 1) {
                    x = min(x, lab[i] >> 1);
                }
            }
            FOR(i, m) {
                if (st[i] == i && sl[i] && s[i] != 1) {
                    x = min(x, dvd(e[sl[i]][i]) >> s[i] + 1);
                }
            }
            FOR(i, n) {
                if (~s[st[i]]) {
                    if ((lab[i] += (s[st[i]] * 2 - 1) * x) <= 0) return 0;
                }
            }
            for (int i = n + 1; i <= m; i++) {
                if (st[i] == i && ~s[st[i]]) {
                    lab[i] += (2 - s[st[i]] * 4) * x;
                }
            }
            h = 1, t = 0;
            FOR(i, m) {
                if (st[i] == i && sl[i] && st[sl[i]] != i && !dvd(e[sl[i]][i]) && on(e[sl[i]][i])) {
                    return 1;
                }
            }
            for (int i = n + 1; i <= m; i++) {
                if (st[i] == i && s[i] == 1 && !lab[i]) ex(i);
            }
        }
        return 0;
    }
    int work() {
        m = n;
        id = 0;
        fill(ed.begin() + 1, ed.begin() + m + 1, 0);
        fill(lk.begin() + 1, lk.begin() + m + 1, 0);
        iota(st.begin() + 1, st.begin() + n + 1, 1);
        T wm = 0; int r = 0;
        FOR(i, n) FOR(j, n) {
            e[i][j] = {i, j, 0};
        }
        for (auto [u, v, w] : edges) {
            wm = max(wm, e[v][u].w = e[u][v].w = max(e[u][v].w, (T)w));
        }
        FOR(i, n) { p[i].clear(); }
        FOR(i, n) FOR(j, n) {
            b[i][j] = i * (i == j);
        }
        fill(lab.begin() + 1, lab.begin() + n + 1, wm);
        while (bfs()) {};
        matchAns.clear();
        FOR(i, n) if (lk[i]) {
            r += e[i][lk[i]].w;
            if (i < lk[i]) {
                matchAns.push_back({i, lk[i]});
            }
        }
        return r / 2;
    }
    vector<array<int, 2>> answer() {
        return matchAns;
    }
};
#undef dvd
#undef FOR
#undef ALL
```

用法：先 `GeneralWeightedMatching G(n);` ，注意这个模板点编号从 `1` 开始。反复调用 `G.add(u, v, w);` 加边，之后调用 `G.work();` 返回最大权匹配的权值和；若需要方案，可调用 `G.answer()` 返回所有匹配边。

### 二分图最大匹配

> 二分图：一个图能被分为左右两部分，任何一条边的两个端点都不在同一部分中。
> 
> 匹配（独立边集）：一个边的集合，这些边没有公共顶点。
> 
> 二分图最大匹配即找到边的数量最多的那个匹配。
> 
> 一般我们规定，左半部包含 $n_1$ 个点（编号 $1 - n_1$），右半部包含 $n_2$ 个点（编号 $1-n_2$ ），保证任意一条边的两个端点都不可能在同一部分中。

#### 匈牙利算法解

 $\mathcal O (NM)$ 。

```c++
struct HungaryMatch {
    int n1, n2;
    vector<vector<int>> ver;
    vector<int> match;
    HungaryMatch(int n1, int n2) : n1(n1), n2(n2) {
        ver.resize(n1 + 1);
        match.resize(n2 + 1);
    }
    void add(int x, int y) { // 只需要建立左到右的单向边
        ver[x].push_back(y);
    }
    bool dfs(int x, vector<int> &vis) {
        for (auto y : ver[x]) {
            if (vis[y]) continue;
            vis[y] = 1;
            if (!match[y] || dfs(match[y], vis)) {
                match[y] = x;
                return true;
            }
        }
        return false;
    }
    int work() {
        fill(match.begin(), match.end(), 0);
        int ans = 0;
        for (int i = 1; i <= n1; ++i) {
            vector<int> vis(n2 + 1);
            if (dfs(i, vis)) {
                ans++;
            }
        }
        return ans;
    }
    vector<array<int, 2>> answer() {
        vector<array<int, 2>> ans;
        for (int i = 1; i <= n2; ++i) {
            if (match[i]) {
                ans.push_back({match[i], i});
            }
        }
        return ans;
    }
};
```

用法：先 `HungaryMatch G(n1, n2);` ，再 `G.add(x, y);` 加边。调用 `G.work();` 返回最大匹配数；若需要具体方案，可在运行后调用 `G.answer()` 获取匹配边。

#### HopcroftKarp 算法解

该算法基于分层图增广路思想，常数极小，且引入随机化，几乎卡不掉。最坏时间复杂度为 $\mathcal O(\sqrt NM)$ ，经[测试](https://judge.yosupo.jp/problem/bipartitematching)，在 $N,M$ 均为 $2 \times 10^5$ 的情况下能在 $\sf 60ms$ 内跑完。

```c++
struct HopcroftKarp {
    int n, m;
    vector<array<int, 2>> ver;
    vector<int> l, r;

    HopcroftKarp(int n, int m) : n(n), m(m) { // 左右半部
        l.assign(n, -1);
        r.assign(m, -1);
    }
    void add(int x, int y) {
        ver.push_back({x, y});
    }
    int work() {
        vector<int> adj(ver.size());

        mt19937 rgen(chrono::steady_clock::now().time_since_epoch().count());
        shuffle(ver.begin(), ver.end(), rgen); // 随机化防卡

        vector<int> deg(n + 1);
        for (auto &[u, v] : ver) {
            deg[u]++;
        }
        for (int i = 1; i <= n; i++) {
            deg[i] += deg[i - 1];
        }
        for (auto &[u, v] : ver) {
            adj[--deg[u]] = v;
        }

        int ans = 0;
        vector<int> a, p, q(n);
        while (true) {
            a.assign(n, -1), p.assign(n, -1);

            int t = 0;
            for (int i = 0; i < n; i++) {
                if (l[i] == -1) {
                    q[t++] = a[i] = p[i] = i;
                }
            }

            bool match = false;
            for (int i = 0; i < t; i++) {
                int x = q[i];
                if (~l[a[x]]) continue;

                for (int j = deg[x]; j < deg[x + 1]; j++) {
                    int y = adj[j];
                    if (r[y] == -1) {
                        while (~y) {
                            r[y] = x;
                            swap(l[x], y);
                            x = p[x];
                        }
                        match = true;
                        ++ans;
                        break;
                    }
                    if (p[r[y]] == -1) {
                        q[t++] = y = r[y];
                        p[y] = x;
                        a[y] = a[x];
                    }
                }
            }
            if (!match) break;
        }
        return ans;
    }
    vector<array<int, 2>> answer() {
        vector<array<int, 2>> ans;
        for (int i = 0; i < n; i++) {
            if (~l[i]) {
                ans.push_back({i, l[i]});
            }
        }
        return ans;
    }
};
```

用法：先 `HopcroftKarp G(n1, n2);` ，注意这个模板左右两侧都采用 `0-indexed`。调用 `G.add(x, y);` 加边，`G.work();` 返回最大匹配数，`G.answer()` 返回所有匹配边。

### 二分图最大权匹配（二分图完美匹配）

> 定义：找到边权和最大的那个匹配。
> 
> 一般我们规定，左半部包含 $n_1$ 个点（编号 $1 - n_1$），右半部包含 $n_2$ 个点（编号 $1-n_2$ ）。

使用匈牙利算法（KM算法）解，时间复杂度为 $\mathcal O(N^3)$ 。下方模板用于求解最大权值、且可以输出其中一种可行方案，例题为 [UOJ #80. 二分图最大权匹配](https://uoj.ac/problem/80) 。

```c++
struct MaxCostMatch {
    vector<int> ansl, ansr, pre;
    vector<int> lx, ly;
    vector<vector<int>> ver;
    int n;

    MaxCostMatch(int n) : n(n) {
        ver.resize(n + 1, vector<int>(n + 1));
        ansl.resize(n + 1, -1);
        ansr.resize(n + 1, -1);
        lx.resize(n + 1);
        ly.resize(n + 1, -1E18);
        pre.resize(n + 1);
    }
    void add(int x, int y, int w) {
        ver[x][y] = w;
    }
    void bfs(int x) {
        vector<bool> visl(n + 1), visr(n + 1);
        vector<int> slack(n + 1, 1E18);
        queue<int> q;
        function<bool(int)> check = [&](int x) {
            visr[x] = 1;
            if (~ansr[x]) {
                q.push(ansr[x]);
                visl[ansr[x]] = 1;
                return false;
            }
            while (~x) {
                ansr[x] = pre[x];
                swap(x, ansl[pre[x]]);
            }
            return true;
        };
        q.push(x);
        visl[x] = 1;
        while (1) {
            while (!q.empty()) {
                int x = q.front();
                q.pop();
                for (int y = 1; y <= n; ++y) {
                    if (visr[y]) continue;
                    int del = lx[x] + ly[y] - ver[x][y];
                    if (del < slack[y]) {
                        pre[y] = x;
                        slack[y] = del;
                        if (!slack[y] && check(y)) return;
                    }
                }
            }
            int val = 1E18;
            for (int i = 1; i <= n; ++i) {
                if (!visr[i]) {
                    val = min(val, slack[i]);
                }
            }
            for (int i = 1; i <= n; ++i) {
                if (visl[i]) lx[i] -= val;
                if (visr[i]) {
                    ly[i] += val;
                } else {
                    slack[i] -= val;
                }
            }
            for (int i = 1; i <= n; ++i) {
                if (!visr[i] && !slack[i] && check(i)) {
                    return;
                }
            }
        }
    }
    int work() {
        for (int i = 1; i <= n; ++i) {
            for (int j = 1; j <= n; ++j) {
                ly[i] = max(ly[i], ver[j][i]);
            }
        }
        for (int i = 1; i <= n; ++i) bfs(i);
        int res = 0;
        for (int i = 1; i <= n; ++i) {
            res += ver[i][ansl[i]];
        }
        return res;
    }
    pair<vector<int>, vector<int>> answer(int x, int y) { // 获取方案 (0 代表无匹配)
        vector<int> left(x + 1), right(y + 1);
        for (int i = 1; i <= x; ++i) {
            left[i] = (ver[i][ansl[i]] ? ansl[i] : 0);
        }
        for (int i = 1; i <= y; ++i) {
            right[i] = (ver[i][ansr[i]] ? ansr[i] : 0);
        }
        return {left, right};
    }
};
```

用法：先 `MaxCostMatch G(max(n1, n2));` ，再 `G.add(x, y, w);` 加边权。调用 `G.work();` 返回最大权完美匹配的权值和；若需要方案，可调用 `auto [left, right] = G.answer(n1, n2);`，其中 `left[i]` 表示左侧点 `i` 匹配到的右侧点编号，`right[i]` 同理。

### 最长路（topsort+DP算法）

计算一张 $\tt DAG$ 中的最长路径，在执行前可能需要使用 $\tt tarjan$ 重构一张正确的 $\tt DAG$ ，复杂度 $\mathcal O(N+M)$ 。

```c++
struct DAG {
    static const int INF = 1E18;
    int n;
    vector<vector<pair<int, int>>> ver;
    vector<int> deg, dis;
    DAG(int n) : n(n) {
        ver.resize(n + 1);
        deg.resize(n + 1);
        dis.resize(n + 1);
    }
    void add(int x, int y, int w) {
        ver[x].push_back({y, w});
        ++deg[y];
    }
    void init() {
        fill(dis.begin(), dis.end(), -INF);
    }
    int work(int s, int t) {
        init();
        vector<int> in = deg;
        queue<int> q;
        for (int i = 1; i <= n; i++) {
            if (in[i] == 0) {
                q.push(i);
            }
        }
        dis[s] = 0;
        while (!q.empty()) {
            int x = q.front();
            q.pop();
            for (auto [y, w] : ver[x]) {
                if (dis[x] > -INF / 2) {
                    dis[y] = max(dis[y], dis[x] + w);
                }
                --in[y];
                if (in[y] == 0) {
                    q.push(y);
                }
            }
        }
        return dis[t];
    }
    int getDis(int x) {
        return dis[x];
    }
};
```

用法：先 `DAG G(n);` ，再 `G.add(x, y, w);` 建有向边。调用 `G.work(s, t);` 返回从 `s` 到 `t` 的最长路；若需要查询任意点的最长路值，可在运行后调用 `G.getDis(x)` 。

### 最短路径树（SPT问题）

> 定义：在一张无向带权联通图中，有这样一棵**生成树**：满足从根节点到任意点的路径都为原图中根到任意点的最短路径。
> 
> 性质：记根节点 $Root$ 到某一结点 $x$ 的最短距离 $dis_{Root,x}$ ，在 $SPT$ 上这两点之间的距离为 $len_{Root,x}$ ——则两者长度相等。

该算法与最小生成树无关，基于最短路 $\tt Dijkstra$ 算法完成（但多了个等于号）。下方代码实现的功能为：读入图后，输出以 $1$ 为根的 $\tt SPT$ 所使用的各条边的编号、边权和。

```c++
struct ShortestPathTree {
    static const int INF = 1E18;
    int n, root, sum;
    vector<vector<array<int, 3>>> ver;
    vector<int> dis, pre, preId, preWeight, vis;
    ShortestPathTree(int n) {
        this->n = n;
        ver.resize(n + 1);
        dis.resize(n + 1);
        pre.resize(n + 1);
        preId.resize(n + 1);
        preWeight.resize(n + 1);
        vis.resize(n + 1);
        root = 1;
        sum = 0;
    }
    void add(int x, int y, int w, int id) {
        ver[x].push_back({y, w, id});
        ver[y].push_back({x, w, id});
    }
    void init() {
        fill(dis.begin(), dis.end(), INF);
        fill(pre.begin(), pre.end(), 0);
        fill(preId.begin(), preId.end(), 0);
        fill(preWeight.begin(), preWeight.end(), 0);
        fill(vis.begin(), vis.end(), 0);
        sum = 0;
    }
    void work(int s = 1) { // 注意这里是 >=，用于恢复一棵最短路径树
        init();
        root = s;
        using PII = pair<int, int>;
        priority_queue<PII, vector<PII>, greater<PII>> q;
        q.push({0, s});
        dis[s] = 0;
        while (!q.empty()) {
            int x = q.top().second;
            q.pop();
            if (vis[x]) continue;
            vis[x] = 1;
            for (auto [y, w, id] : ver[x]) {
                if (dis[y] >= dis[x] + w) {
                    dis[y] = dis[x] + w;
                    pre[y] = x;
                    preId[y] = id;
                    preWeight[y] = w;
                    q.push({dis[y], y});
                }
            }
        }
        for (int i = 1; i <= n; ++i) {
            if (i != root && preId[i]) {
                sum += preWeight[i];
            }
        }
    }
    int getDis(int x) {
        return dis[x];
    }
    vector<int> getEdgeIds() {
        vector<int> ans;
        for (int i = 1; i <= n; ++i) {
            if (i != root && preId[i]) {
                ans.push_back(preId[i]);
            }
        }
        return ans;
    }
    int getWeightSum() {
        return sum;
    }
};
```

用法：先 `ShortestPathTree G(n);` ，再 `G.add(x, y, w, id);` 加无向边并记录边编号。调用 `G.work(root);` 后，`G.getDis(x)` 表示根到点 `x` 的最短距离，`G.getEdgeIds()` 返回所选最短路径树中的边编号集合，`G.getWeightSum()` 返回这些边的边权和。

### 无源汇点的最小割问题 Stoer–Wagner

> 也称为全局最小割。定义补充（与《网络流》中的定义不同）：
> 
> **割**：是一个边集，去掉其中所有边能使一张网络流图不再连通（即分成两个子图）。

通过**递归**的方式来解决**无向正权图**上的全局最小割问题，算法复杂度 $\mathcal O(VE + V^{2}\log V)$ ，一般可近似看作 $\mathcal O(V^3)$ 。

```c++
struct StoerWagner {
    static const int INF = 1E18;
    int n;
    vector<vector<int>> edge;
    StoerWagner(int n) {
        this->n = n;
        edge.resize(n + 1, vector<int>(n + 1));
    }
    void add(int x, int y, int w) {
        edge[x][y] += w;
        edge[y][x] += w;
    }
    bool connected() {
        int s = 0;
        for (int i = 1; i <= n; ++i) {
            for (int j = 1; j <= n; ++j) {
                if (edge[i][j]) {
                    s = i;
                    break;
                }
            }
            if (s) break;
        }
        if (!s) return n <= 1;
        vector<int> vis(n + 1);
        function<void(int)> dfs = [&](int x) {
            vis[x] = 1;
            for (int y = 1; y <= n; ++y) {
                if (edge[x][y] && !vis[y]) {
                    dfs(y);
                }
            }
        };
        dfs(s);
        for (int i = 1; i <= n; ++i) {
            if (!vis[i]) return false;
        }
        return true;
    }
    int work() {
        if (!connected()) return 0;
        vector<vector<int>> g = edge;
        vector<int> bin(n + 1);
        int minCut = INF, S = 1, T = 1;
        auto contract = [&]() -> int {
            vector<int> dis(n + 1), vis(n + 1);
            int cut = 0;
            for (int i = 1; i <= n; ++i) {
                int k = -1, maxc = -1;
                for (int j = 1; j <= n; ++j) {
                    if (!bin[j] && !vis[j] && dis[j] > maxc) {
                        k = j;
                        maxc = dis[j];
                    }
                }
                if (k == -1) return cut;
                S = T, T = k, cut = maxc;
                vis[k] = 1;
                for (int j = 1; j <= n; ++j) {
                    if (!bin[j] && !vis[j]) {
                        dis[j] += g[k][j];
                    }
                }
            }
            return cut;
        };
        for (int i = 1; i < n; ++i) {
            int val = contract();
            bin[T] = 1;
            minCut = min(minCut, val);
            if (!minCut) return 0;
            for (int j = 1; j <= n; ++j) {
                if (!bin[j]) {
                    g[S][j] += g[T][j];
                    g[j][S] += g[j][T];
                }
            }
        }
        return minCut;
    }
};
```

用法：先 `StoerWagner G(n);` ，再 `G.add(x, y, w);` 加无向正权边。调用 `G.work();` 返回全局最小割；若原图不连通，则返回 `0` 。

### 欧拉路径/欧拉回路 Hierholzers

> 欧拉路径：一笔画完图中全部边，画的顺序就是一个可行解；当起点终点相同时称欧拉回路。

#### 有向图欧拉路径存在判定

有向图欧拉路径存在：$\tt ^1$ 恰有一个点出度比入度多 $1$ （为起点）；$\tt ^2$ 恰有一个点入度比出度多 $1$ （为终点）；$\tt ^3$ 恰有 $N-2$ 个点入度均等于出度。如果是欧拉回路，则上方起点与终点的条件不存在，全部点均要满足最后一个条件。

```c++
struct DirectedEulerGraph {
    int n;
    vector<multiset<int>> ver;
    vector<vector<int>> undir;
    vector<int> degI, degO;
    DirectedEulerGraph(int n) {
        this->n = n;
        ver.resize(n + 1);
        undir.resize(n + 1);
        degI.resize(n + 1);
        degO.resize(n + 1);
    }
    void add(int x, int y) {
        ver[x].insert(y);
        undir[x].push_back(y);
        undir[y].push_back(x);
        degO[x]++;
        degI[y]++;
    }
    bool connected() {
        int s = 0;
        for (int i = 1; i <= n; ++i) {
            if (degI[i] + degO[i]) {
                s = i;
                break;
            }
        }
        if (!s) return true;
        vector<int> vis(n + 1);
        function<void(int)> dfs = [&](int x) {
            vis[x] = 1;
            for (auto y : undir[x]) {
                if (!vis[y]) dfs(y);
            }
        };
        dfs(s);
        for (int i = 1; i <= n; ++i) {
            if (degI[i] + degO[i] && !vis[i]) return false;
        }
        return true;
    }
    bool hasEulerPath() {
        if (!connected()) return false;
        int s = 0, t = 0;
        for (int i = 1; i <= n; ++i) {
            if (degO[i] == degI[i] + 1) s++;
            else if (degI[i] == degO[i] + 1) t++;
            else if (degI[i] != degO[i]) return false;
        }
        return (s == 1 && t == 1) || (s == 0 && t == 0);
    }
    int getStart() {
        for (int i = 1; i <= n; ++i) {
            if (degO[i] == degI[i] + 1) return i;
        }
        for (int i = 1; i <= n; ++i) {
            if (degO[i]) return i;
        }
        return 1;
    }
    vector<int> work(int s = -1) {
        if (s == -1) s = getStart();
        vector<int> ans;
        function<void(int)> dfs = [&](int x) {
            while (!ver[x].empty()) {
                int y = *ver[x].begin();
                ver[x].erase(ver[x].begin());
                dfs(y);
            }
            ans.push_back(x);
        };
        dfs(s);
        reverse(ans.begin(), ans.end());
        return ans;
    }
};
```

用法：先 `DirectedEulerGraph G(n);` ，再 `G.add(x, y);` 加有向边。调用 `G.hasEulerPath();` 判断是否存在欧拉路径；若存在，调用 `G.work();` 返回一条字典序较小的欧拉路径点序列。

#### 无向图欧拉路径存在判定

无向图欧拉路径存在：$\tt ^1$ 恰有两个点度数为奇数（为起点与终点）；$\tt ^2$ 恰有 $N-2$ 个点度数为偶数。

```c++
struct UndirectedEulerGraph {
    int n, m;
    vector<multiset<pair<int, int>>> ver;
    vector<int> deg;
    UndirectedEulerGraph(int n) {
        this->n = n;
        m = 0;
        ver.resize(n + 1);
        deg.resize(n + 1);
    }
    void add(int x, int y) {
        ++m;
        ver[x].insert({y, m});
        ver[y].insert({x, m});
        deg[x]++;
        deg[y]++;
    }
    bool connected() {
        int s = 0;
        for (int i = 1; i <= n; ++i) {
            if (deg[i]) {
                s = i;
                break;
            }
        }
        if (!s) return true;
        vector<int> vis(n + 1);
        function<void(int)> dfs = [&](int x) {
            vis[x] = 1;
            for (auto [y, id] : ver[x]) {
                if (!vis[y]) dfs(y);
            }
        };
        dfs(s);
        for (int i = 1; i <= n; ++i) {
            if (deg[i] && !vis[i]) return false;
        }
        return true;
    }
    bool hasEulerPath() {
        if (!connected()) return false;
        int odd = 0;
        for (int i = 1; i <= n; ++i) {
            odd += deg[i] % 2;
        }
        return odd == 0 || odd == 2;
    }
    int getStart() {
        for (int i = 1; i <= n; ++i) {
            if (deg[i] % 2) return i;
        }
        for (int i = 1; i <= n; ++i) {
            if (deg[i]) return i;
        }
        return 1;
    }
    vector<pair<int, int>> work(int s = -1) {
        if (s == -1) s = getStart();
        vector<pair<int, int>> ans;
        function<void(int)> dfs = [&](int x) {
            while (!ver[x].empty()) {
                auto [y, id] = *ver[x].begin();
                ver[x].erase(ver[x].begin());
                ver[y].erase(ver[y].find({x, id}));
                dfs(y);
                ans.push_back({x, y});
            }
        };
        dfs(s);
        reverse(ans.begin(), ans.end());
        return ans;
    }
};
```

用法：先 `UndirectedEulerGraph G(n);` ，再 `G.add(x, y);` 加无向边。调用 `G.hasEulerPath();` 判断是否存在欧拉路径；若存在，调用 `G.work();` 返回按经过顺序排列的边序列。

### 差分约束

给出一组包含 $m$ 个不等式，有 $n$ 个未知数的形如：$ \begin{cases} u_1-v_1\leq w_1 \\u_2-v_2 \leq w_2 \\ \cdots\\ u_m -v_m\leq w_m\end{cases}$的不等式组，求任意一组满足这个不等式组的解。下方使用 Bellman-Ford 式松弛判负环，复杂度 $\mathcal O(nm)$ 。[参考](https://www.luogu.com.cn/problem/P5960)

```c++
struct DifferenceConstraints {
    int n;
    vector<array<int, 3>> e;
    vector<int> dis;
    DifferenceConstraints(int n) {
        this->n = n;
        dis.resize(n + 1);
    }
    void add(int u, int v, int w) { // u - v <= w
        e.push_back({v, u, w});
    }
    bool work() {
        fill(dis.begin(), dis.end(), 0); // 超级源点向所有点连权值为 0 的边
        for (int i = 1; i <= n; ++i) {
            bool update = false;
            for (auto [u, v, w] : e) {
                if (dis[v] > dis[u] + w) {
                    dis[v] = dis[u] + w;
                    update = true;
                    if (i == n) {
                        return false;
                    }
                }
            }
            if (!update) {
                break;
            }
        }
        return true;
    }
    int getVal(int x) {
        return dis[x];
    }
};
```

用法：先 `DifferenceConstraints G(n);` ，再对每个不等式 `u - v <= w` 调用 `G.add(u, v, w);`。调用 `G.work();` 后，若返回 `false` 表示无解；否则 `G.getVal(i)` 给出一组可行解。

### 2-Sat

#### 基础封装

基于 tarjan 缩点，时间复杂度为 $\mathcal O(N+M)$ 。注意下标从 $0$ 开始，答案输出为字典序最小的一个可行解。

```c++
struct TwoSat {
    int n;
    vector<vector<int>> e;
    vector<bool> ans;
    TwoSat(int n) : n(n), e(2 * n), ans(n) {}
    void add(int u, bool f, int v, bool g) {
        e[2 * u + !f].push_back(2 * v + g);
        e[2 * v + !g].push_back(2 * u + f);
    }
    bool work() {
        vector<int> id(2 * n, -1), dfn(2 * n, -1), low(2 * n, -1);
        vector<int> stk;
        int now = 0, cnt = 0;
        auto tarjan = [&](auto self, int u) -> void {
            stk.push_back(u);
            dfn[u] = low[u] = now++;
            for (auto v : e[u]) {
                if (dfn[v] == -1) {
                    self(self, v);
                    low[u] = min(low[u], low[v]);
                } else if (id[v] == -1) {
                    low[u] = min(low[u], dfn[v]);
                }
            }
            if (dfn[u] == low[u]) {
                int v;
                do {
                    v = stk.back();
                    stk.pop_back();
                    id[v] = cnt;
                } while (v != u);
                ++cnt;
            }
        };
        for (int i = 0; i < 2 * n; ++i) {
            if (dfn[i] == -1) {
                tarjan(tarjan, i);
            }
        }
        for (int i = 0; i < n; ++i) {
            if (id[2 * i] == id[2 * i + 1]) return false;
            ans[i] = id[2 * i] > id[2 * i + 1];
        }
        return true;
    }
    vector<bool> answer() {
        return ans;
    }
    bool check(int x, int y) {
        vector<int> vis(2 * n);
        auto dfs = [&](auto self, int u) -> void {
            vis[u] = 1;
            for (auto v : e[u]) {
                if (vis[v]) continue;
                self(self, v);
            }
        };
        dfs(dfs, x);
        return vis[y];
    }
    vector<int> uniqueAnswer() {
        vector<int> res(n, -1);
        for (int i = 0; i < n; ++i) {
            if (check(2 * i, 2 * i + 1)) {
                res[i] = 1;
            } else if (check(2 * i + 1, 2 * i)) {
                res[i] = 0;
            }
        }
        return res;
    }
};
```

用法：先 `TwoSat G(n);` ，其中每个变量下标范围为 `[0, n - 1]`。调用 `G.add(u, f, v, g);` 表示加入子句 `(u == f) or (v == g)`；调用 `G.work();` 判断是否有解，若有解则可通过 `G.answer()` 取得一组可行布尔赋值。若题目要求“答案不唯一时不输出”，则继续调用 `G.uniqueAnswer()`：返回值中 `0/1` 表示该变量被唯一确定，`-1` 表示该变量取值不唯一。

#### 答案不唯一时不输出

在运行后针对每一个点进行一次 dfs，时间复杂度为 $\mathcal O(N^2)$ ，当且仅当答案唯一时才输出，否则输出 `?` 替代。

```c++
auto res = sat.uniqueAnswer();
for (int i = 0; i < n; i++) {
    if (res[i] == -1) {
        cout << "? ";
    } else {
        cout << res[i] << " ";
    }
}
```
