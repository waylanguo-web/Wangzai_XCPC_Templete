## 第二章：树上问题

### 树的直径

> **用途：** 求无权树的直径长度。基于“从任意点出发的最远点必为直径一端”的性质，两次 DFS 即可。
>
> **适用条件：** 无权树（边权均为 1）；输入为森林时亦可，`getlen` 只计算 `root` 所在连通块的直径。
>
> **前置依赖：** 无。
>
> **用法：** `Tree T(n);` → `T.add(x,y)` 加边 → `T.getlen(root)` 返回直径长度。
>
> **注意事项：** 使用显式栈迭代 DFS，常数更小且无递归爆栈问题。

| 操作/结构          | 含义                   | 复杂度                    |
| -------------- | -------------------- | ---------------------- |
| `Tree(n)`      | 构造 $n$ 个节点的空树        | $O(n)$                 |
| `add(x, y)`    | 添加一条无向边              | $O(1)$ 均摊              |
| `getlen(root)` | 返回 `root` 所在连通块的直径长度 | $O(k)$，其中 $k$ 为该连通块节点数 |


```cpp
struct Tree {
    int n;
    vector<vector<int>> ver;

    Tree(int n) {
        this->n = n;
        ver.resize(n + 1);
    }

    void add(int x, int y) {
        ver[x].push_back(y);
        ver[y].push_back(x);
    }

    pair<int,int> dfs(int s) {
        int pos = s, mx = 0;
        vector<array<int,3>> st;
        st.push_back({s, 0, 0});
        while(!st.empty()) {
            array<int,3> t = st.back();
            st.pop_back();
            int x = t[0], fa = t[1], dep = t[2];
            if(dep > mx) {
                mx = dep;
                pos = x;
            }
            for(auto y : ver[x]) {
                if(y == fa) continue;
                st.push_back({y, x, dep + 1});
            }
        }
        return {pos, mx};
    }

    int getlen(int root) {
        int st = dfs(root).first;
        return dfs(st).second;
    }
};
```

### 树论大封装（直径+重心+中心）

> **用途：** 求带权树的直径、半径、中心、重心。`dfs1`+`dfs2` 预处理后 `getCenter` 以 $O(n)$ 求中心与直径；`getCog` 以 $O(n)$ 求重心。
>
> **适用条件：** 带权树（边权非负）；节点编号 $1\sim n$；需连通（森林需逐连通块处理）。
>
> **前置依赖：** 无。
>
> **用法：** `Tree T(n);` → `T.add(u,v,w)` 加边 → `T.dfs1(1,0); T.dfs2(1,0); T.getCenter();` 求中心/直径 → `T.getCog();` 求重心。
>
> **注意事项：** `dfs1`、`dfs2` 必须在 `getCenter` 之前调用；`getCog` 独立于前三者，可单独调用。

| 操作/结构 | 含义 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- | --- |
| `Tree(n)` | 构造 $n$ 节点空树 | $O(n)$ | $O(n)$ |
| `add(u,v,w)` | 添加带权无向边 | $O(1)$ 均摊 | — |
| `dfs1(root,0)` | 预处理每节点向下最长/次长路径 | $O(n)$ | $O(n)$ 递归栈 |
| `dfs2(root,0)` | 预处理每节点向上最长路径 | $O(n)$ | $O(n)$ 递归栈 |
| `getCenter()` | 求中心 `center`、半径 `radius`、直径 `diam` | $O(n)$ | — |
| `getCog()` | 求重心 `cog`、最大子树大小 `rem` | $O(n)$ | $O(n)$ |

```c++
struct Tree {
    int n;
    vector<vector<pair<int, int>>> e;
    vector<int> d1, d2, s1, s2, up;
    Tree(int n) {
        this->n = n;
        e.resize(n + 1);
        d1.resize(n + 1);
        d2.resize(n + 1);
        s1.resize(n + 1);
        s2.resize(n + 1);
        up.resize(n + 1);
    }
    void add(int u, int v, int w) {
        e[u].push_back({w, v});
        e[v].push_back({w, u});
    }
    void dfs1(int u, int fa) {
        for (auto &p : e[u]) {
            int w = p.first, v = p.second;
            if (v == fa) continue;
            dfs1(v, u);
            int x = d1[v] + w;
            if (x > d1[u]) {
                d2[u] = d1[u], s2[u] = s1[u];
                d1[u] = x, s1[u] = v;
            } else if (x > d2[u]) {
                d2[u] = x, s2[u] = v;
            }
        }
    }
    void dfs2(int u, int fa) {
        for (auto &p : e[u]) {
            int w = p.first, v = p.second;
            if (v == fa) continue;
            if (s1[u] == v) {
                up[v] = max(up[u], d2[u]) + w;
            } else {
                up[v] = max(up[u], d1[u]) + w;
            }
            dfs2(v, u);
        }
    }

    int radius, center, diam;
    void getCenter() {
        center = 1; //中心
        for (int i = 1; i <= n; i++) {
            if (max(d1[i], up[i]) < max(d1[center], up[center])) {
                center = i;
            }
        }
        radius = max(d1[center], up[center]); //距离最远点的距离的最小值
        diam = d1[center] + max(d2[center], up[center]); //直径
    }

    int rem; //删除重心后剩余连通块体积的最小值
    int cog; //重心
    vector<bool> vis;
    void getCog() {
        vis.resize(n + 1);
        rem = INT_MAX;
        cog = 1;
        dfsCog(1);
    }
    int dfsCog(int u) {
        vis[u] = true;
        int s = 1, res = 0;
        for (auto &p : e[u]) {
            int v = p.second;
            if (vis[v]) continue;
            int t = dfsCog(v);
            res = max(res, t);
            s += t;
        }
        res = max(res, n - s);
        if (res < rem) {
            rem = res;
            cog = u;
        }
        return s;
    }
};
```

### 点分治 / 树的重心

重心的定义：删除树上的某一个点，会得到若干棵子树；删除某点后，得到的最大子树最小，这个点称为重心。我们假设某个点是重心，记录此时最大子树的最小值，遍历完所有点后取最大值即可。

> 重心的性质：重心最多可能会有两个，且此时两个重心相邻。

点分治的一般过程是：取重心为新树的根，随后使用 $\tt dfs$ 处理当前这棵树，灵活运用 `child` 和 `pre` 两个数组分别计算通过根节点、不通过根节点的路径信息，根据需要进行答案的更新；再对子树分治，寻找子树的重心，……。时间复杂度降至 $\mathcal O(N\log N)$ 。

> **用途：** 判定树上是否存在长度为 $q_i$ 的路径（点分治示例）。修改 `clac` 内逻辑可适配各类路径统计问题。
>
> **适用条件：** 带权树；边权非负；节点编号 $1\sim n$。
>
> **前置依赖：** 全局变量 `ver`（邻接表，`vector<vector<pair<int,int>>>`）、`n`、`m`（询问数）、`q[]`（询问数组）、`ans[]`（答案数组）。
>
> **用法：** 建好 `ver` 后执行 `get(get,1,0,n); dfz(dfz,root,0);`，`ans[i]=1` 表示存在长度为 `q[i]` 的路径。
>
> **注意事项：** `MaxTree` 每次找重心前须重置为 `1e18`；`vis` 标记的是已分治过的重心，不可复用。

| 操作/结构 | 含义 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- | --- |
| `get(get,x,fa,n)` | 求当前子树重心 | $O(n)$ | $O(n)$ |
| `clac(x)` | 以 $x$ 为根统计路径 | $O(n)$ | $O(n)$ |
| `dfz(dfz,x,fa)` | 点分治主过程 | $O(n\log n)$ | $O(n)$ 递归栈 |

```c++
int root = 0, MaxTree = 1e18; //分别代表重心下标、最大子树大小
vector<int> vis(n + 1), siz(n + 1);
auto get = [&](auto self, int x, int fa, int n) -> void { // 获取树的重心
    siz[x] = 1;
    int val = 0;
    for (auto &p : ver[x]) {
        int y = p.first, w = p.second;
        if (y == fa || vis[y]) continue;
        self(self, y, x, n);
        siz[x] += siz[y];
        val = max(val, siz[y]);
    }
    val = max(val, n - siz[x]);
    if (val < MaxTree) {
        MaxTree = val;
        root = x;
    }
};

auto clac = [&](int x) -> void { // 以 x 为新的根，维护询问
    unordered_set<int> pre = {0}; // 记录到根节点 x 距离为 i 的路径是否存在
    vector<int> dis(n + 1);
    for (auto &p : ver[x]) {
        int y = p.first, w = p.second;
        if (vis[y]) continue;
        vector<int> child; // 记录 x 的子树节点的深度信息
        auto dfs = [&](auto self, int x, int fa) -> void {
            child.push_back(dis[x]);
            for (auto &ed : ver[x]) {
                int ny = ed.first, nw = ed.second;
                if (ny == fa || vis[ny]) continue;
                dis[ny] = dis[x] + nw;
                self(self, ny, x);
            }
        };
        dis[y] = w;
        dfs(dfs, y, x);

        for (auto it : child) {
            for (int i = 1; i <= m; i++) { // 根据询问更新值
                if (q[i] < it || !pre.count(q[i] - it)) continue;
                ans[i] = 1;
            }
        }
        pre.insert(child.begin(), child.end());
    }
};

auto dfz = [&](auto self, int x, int fa) -> void { // 点分治
    vis[x] = 1; // 标记已经被更新过的旧重心，确保只对子树分治
    clac(x);
    for (auto &p : ver[x]) {
        int y = p.first;
        if (y == fa || vis[y]) continue;
        MaxTree = 1e18;
        get(get, y, x, siz[y]);
        self(self, root, x);
    }
};

get(get, 1, 0, n);
dfz(dfz, root, 0);
```

### 最近公共祖先 LCA

#### 树链剖分解法

> **用途：** 求无权树上两点的 LCA 与距离。
>
> **适用条件：** 无权树；节点编号 $1\sim n$。
>
> **前置依赖：** 无。
>
> **用法：** `HLD T(n);` → `T.add(x,y)` 加边 → `T.work(root);` 预处理 → `T.lca(x,y)` 查询 LCA → `T.clac(x,y)` 查询距离。
>
> **注意事项：** `work` 必须在查询之前调用；默认根为 1，可传参修改。

| 操作/结构 | 含义 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- | --- |
| `HLD(n)` | 构造 $n$ 节点空树 | $O(n)$ | $O(n)$ |
| `add(x,y)` | 添加无向边 | $O(1)$ 均摊 | — |
| `work(root)` | 预处理（两次 DFS） | $O(n)$ | $O(n)$ 递归栈 |
| `lca(x,y)` | 查询 LCA | $O(\log n)$ | — |
| `clac(x,y)` | 查询两点距离 | $O(\log n)$ | — |

```c++
struct HLD {
    int n, idx;
    vector<vector<int>> ver;
    vector<int> siz, dep;
    vector<int> top, son, parent;

    HLD(int n) {
        this->n = n;
        ver.resize(n + 1);
        siz.resize(n + 1);
        dep.resize(n + 1);

        top.resize(n + 1);
        son.resize(n + 1);
        parent.resize(n + 1);
    }
    void add(int x, int y) { // 建立双向边
        ver[x].push_back(y);
        ver[y].push_back(x);
    }
    void dfs1(int x) {
        siz[x] = 1;
        dep[x] = dep[parent[x]] + 1;
        for (auto y : ver[x]) {
            if (y == parent[x]) continue;
            parent[y] = x;
            dfs1(y);
            siz[x] += siz[y];
            if (siz[y] > siz[son[x]]) {
                son[x] = y;
            }
        }
    }
    void dfs2(int x, int up) {
        top[x] = up;
        if (son[x]) dfs2(son[x], up);
        for (auto y : ver[x]) {
            if (y == parent[x] || y == son[x]) continue;
            dfs2(y, y);
        }
    }
    int lca(int x, int y) {
        while (top[x] != top[y]) {
            if (dep[top[x]] > dep[top[y]]) {
                x = parent[top[x]];
            } else {
                y = parent[top[y]];
            }
        }
        return dep[x] < dep[y] ? x : y;
    }
    int clac(int x, int y) { // 查询两点间距离
        return dep[x] + dep[y] - 2 * dep[lca(x, y)];
    }
    void work(int root = 1) { // 在此初始化
        dfs1(root);
        dfs2(root, root);
    }
};
```

#### 树上倍增解法

预处理时间复杂度 $\mathcal O(N\log N)$ ；单次查询 $\mathcal O(\log N)$ ，但是常数比树链剖分解法更大。

**封装一：基础封装，针对无权图。**

> **用途：** 求无权树上两点的 LCA 与距离。
>
> **适用条件：** 无权树；节点编号 $1\sim n$。
>
> **前置依赖：** 无。
>
> **用法：** `Tree T(n);` → `T.add(x,y)` 加边 → `T.work(root);` 预处理 → `T.lca(x,y)` 查询 LCA → `T.clac(x,y)` 查询距离。
>
> **注意事项：** 倍增表第二维固定为 30，支持 $n\le 2^{29}$；常数比树链剖分大。

| 操作/结构 | 含义 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- | --- |
| `Tree(n)` | 构造并预处理 $\lg$ 表 | $O(n)$ | $O(n\log n)$ |
| `add(x,y)` | 添加无向边 | $O(1)$ 均摊 | — |
| `work(root)` | 预处理倍增表 | $O(n\log n)$ | $O(n\log n)$ |
| `lca(x,y)` | 查询 LCA | $O(\log n)$ | — |
| `clac(x,y)` | 查询两点距离 | $O(\log n)$ | — |

```c++
struct Tree {
    int n;
    vector<vector<int>> ver, val;
    vector<int> lg, dep;
    Tree(int n) {
        this->n = n;
        ver.resize(n + 1);
        val.resize(n + 1, vector<int>(30));
        lg.resize(n + 1);
        dep.resize(n + 1);
        for (int i = 1; i <= n; i++) { //预处理 log
            lg[i] = lg[i - 1] + (1 << lg[i - 1] == i);
        }
    }
    void add(int x, int y) { // 建立双向边
        ver[x].push_back(y);
        ver[y].push_back(x);
    }
    void dfs(int x, int fa) {
        val[x][0] = fa; // 储存 x 的父节点
        dep[x] = dep[fa] + 1;
        for (int i = 1; i <= lg[dep[x]]; i++) {
            val[x][i] = val[val[x][i - 1]][i - 1];
        }
        for (auto y : ver[x]) {
            if (y == fa) continue;
            dfs(y, x);
        }
    }
    int lca(int x, int y) {
        if (dep[x] < dep[y]) swap(x, y);
        while (dep[x] > dep[y]) {
            x = val[x][lg[dep[x] - dep[y]] - 1];
        }
        if (x == y) return x;
        for (int k = lg[dep[x]] - 1; k >= 0; k--) {
            if (val[x][k] == val[y][k]) continue;
            x = val[x][k];
            y = val[y][k];
        }
        return val[x][0];
    }
    int clac(int x, int y) { // 倍增查询两点间距离
        return dep[x] + dep[y] - 2 * dep[lca(x, y)];
    }
    void work(int root = 1) { // 在此初始化
        dfs(root, 0);
    }
};
```

**封装二：扩展封装，针对有权图，支持“倍增查询两点路径上的最大边权”功能**。

> **用途：** 求带权树上两点的 LCA、距离及路径上最大边权。
>
> **适用条件：** 带权树；节点编号 $1\sim n$。
>
> **前置依赖：** 无。
>
> **用法：** `Tree T(n);` → `T.add(x,y,w)` 加带权边 → `T.work(root);` 预处理 → `T.lca(x,y)` / `T.clac(x,y)` / `T.query(x,y)` 分别查询 LCA / 距离 / 路径最大边权。
>
> **注意事项：** 倍增表第二维固定为 30，支持 $n\le 2^{29}$。

| 操作/结构 | 含义 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- | --- |
| `Tree(n)` | 构造并预处理 $\lg$ 表 | $O(n)$ | $O(n\log n)$ |
| `add(x,y,w)` | 添加带权无向边 | $O(1)$ 均摊 | — |
| `work(root)` | 预处理倍增表 | $O(n\log n)$ | $O(n\log n)$ |
| `lca(x,y)` | 查询 LCA | $O(\log n)$ | — |
| `clac(x,y)` | 查询两点距离 | $O(\log n)$ | — |
| `query(x,y)` | 查询路径最大边权 | $O(\log n)$ | — |

```c++
struct Tree {
    int n;
    vector<vector<int>> val, Max;
    vector<vector<pair<int, int>>> ver;
    vector<int> lg, dep;
    Tree(int n) {
        this->n = n;
        ver.resize(n + 1);
        val.resize(n + 1, vector<int>(30));
        Max.resize(n + 1, vector<int>(30));
        lg.resize(n + 1);
        dep.resize(n + 1);
        for (int i = 1; i <= n; i++) { //预处理 log
            lg[i] = lg[i - 1] + (1 << lg[i - 1] == i);
        }
    }
    void add(int x, int y, int w) { // 建立双向边
        ver[x].push_back({y, w});
        ver[y].push_back({x, w});
    }
    void dfs(int x, int fa) {
        val[x][0] = fa;
        dep[x] = dep[fa] + 1;
        for (int i = 1; i <= lg[dep[x]]; i++) {
            val[x][i] = val[val[x][i - 1]][i - 1];
            Max[x][i] = max(Max[x][i - 1], Max[val[x][i - 1]][i - 1]);
        }
        for (auto &p : ver[x]) {
            int y = p.first, w = p.second;
            if (y == fa) continue;
            Max[y][0] = w;
            dfs(y, x);
        }
    }
    int lca(int x, int y) {
        if (dep[x] < dep[y]) swap(x, y);
        while (dep[x] > dep[y]) {
            x = val[x][lg[dep[x] - dep[y]] - 1];
        }
        if (x == y) return x;
        for (int k = lg[dep[x]] - 1; k >= 0; k--) {
            if (val[x][k] == val[y][k]) continue;
            x = val[x][k];
            y = val[y][k];
        }
        return val[x][0];
    }
    int clac(int x, int y) { // 倍增查询两点间距离
        return dep[x] + dep[y] - 2 * dep[lca(x, y)];
    }
    int query(int x, int y) { // 倍增查询两点路径上的最大边权（带权图）
        auto get = [&](int x, int y) -> int {
            int ans = 0;
            if (x == y) return ans;
            for (int i = lg[dep[x]]; i >= 0; i--) {
                if (dep[val[x][i]] > dep[y]) {
                    ans = max(ans, Max[x][i]);
                    x = val[x][i];
                }
            }
            ans = max(ans, Max[x][0]);
            return ans;
        };
        int fa = lca(x, y);
        return max(get(x, fa), get(y, fa));
    }
    void work(int root = 1) { // 在此初始化
        dfs(root, 0);
    }
};
```

### 树上路径交

> **用途：** 求树上两条路径 $(x,y)$ 与 $(X,Y)$ 的交集节点数。
>
> **适用条件：** 需已载入任意 LCA 封装（提供 `lca`、`clac`、`dep`）。
>
> **前置依赖：** LCA 封装（`lca(x,y)`、`clac(x,y)`、`dep[]`）。
>
> **用法：** 先完成 LCA 预处理，再调用 `intersection(x,y,X,Y)`，返回交集节点数（0 表示不相交）。
>
> **注意事项：** 四个 LCA 值按深度排序取最深两个作为交集端点；不相交判定为 $dep[t_2]<\max(dep[r],dep[R])$。

```c++
int intersection(int x, int y, int X, int Y) {
    vector<int> t = {lca(x, X), lca(x, Y), lca(y, X), lca(y, Y)};
    sort(t.begin(), t.end(), [&](int a, int b) { return dep[a] < dep[b]; });
    int r = lca(x, y), R = lca(X, Y);
    if (dep[t[2]] < max(dep[r], dep[R])) return 0;
    return 1 + clac(t[2], t[3]);
}
```

### 树上启发式合并 (DSU on tree)

> **用途：** 树上启发式合并，对每个节点 $u$ 求其子树内出现次数最多的颜色（及颜色和）。
>
> **适用条件：** 无权树；节点编号 $1\sim n$；需全局定义 `color[]` 数组。
>
> **前置依赖：** 全局数组 `color[]`（每个节点的颜色）。
>
> **用法：** `HLD T(n);` → `T.add(u,v)` 加边 → `T.dfs1(1,0); T.dfs2(1,0,0);` 预处理后 `T.ans[u]` 即为节点 $u$ 子树内的答案。
>
> **注意事项：** `dfs1` 必须在 `dfs2` 之前调用；`color` 数组须在构造前定义。

| 操作/结构 | 含义 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- | --- |
| `HLD(n)` | 构造 $n$ 节点空树 | $O(n)$ | $O(n)$ |
| `add(u,v)` | 添加无向边 | $O(1)$ 均摊 | — |
| `dfs1(1,0)` | 预处理重儿子 | $O(n)$ | $O(n)$ 递归栈 |
| `dfs2(1,0,0)` | 启发式合并求答案 | $O(n\log n)$ | $O(n)$ 递归栈 |

```c++
struct HLD {
    vector<vector<int>> e;
    vector<int> siz, son, cnt;
    vector<int> ans;
    int sum, Max;
    int hson;
    HLD(int n) {
        e.resize(n + 1);
        siz.resize(n + 1);
        son.resize(n + 1);
        ans.resize(n + 1);
        cnt.resize(n + 1);
        hson = 0;
        sum = 0;
        Max = 0;
    }
    void add(int u, int v) {
        e[u].push_back(v);
        e[v].push_back(u);
    }
    void dfs1(int u, int fa) {
        siz[u] = 1;
        for (auto v : e[u]) {
            if (v == fa) continue;
            dfs1(v, u);
            siz[u] += siz[v];
            if (siz[v] > siz[son[u]]) son[u] = v;
        }
    }
    void calc(int u, int fa, int val) {
        cnt[color[u]] += val;
        if (val > 0) {
            if (cnt[color[u]] > Max) {
                Max = cnt[color[u]];
                sum = color[u];
            } else if (cnt[color[u]] == Max) {
                sum += color[u];
            }
        }
        for (auto v : e[u]) {
            if (v == fa || v == hson) continue;
            calc(v, u, val);
        }
    }
    void dfs2(int u, int fa, int opt) {
        for (auto v : e[u]) {
            if (v == fa || v == son[u]) continue;
            dfs2(v, u, 0);
        }
        if (son[u]) {
            dfs2(son[u], u, 1);
            hson = son[u]; //记录重链编号，计算的时候跳过
        }
        calc(u, fa, 1);
        hson = 0; //消除的时候所有儿子都清除
        ans[u] = sum;
        if (!opt) {
            calc(u, fa, -1);
            sum = 0;
            Max = 0;
        }
    }
};
```
